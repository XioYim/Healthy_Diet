01Начало игры

  • 1Установите подходящий файл: используйте Healthy Diet для вашей версии Minecraft и загрузчика; на мультисервере обе стороны должны быть совместимы.
  • 2Откройте панель питания: введите /headiet, чтобы увидеть свои группы питания и текущие значения.
  • 3Проверьте еду: держите еду и введите /hdinfo, чтобы увидеть настройки сервера для подходящего варианта и открыть локальный просмотрщик. Команда /hdinfo minecraft:apple показывает стандартный стак указанного предмета.
  • 4Посмотрите подсказку: подсказка предмета может показывать питание, повторное употребление и срок годности. Владелец сервера решает, какие строки видны всегда, а какие раскрываются по Shift.
  • 5Проверьте температуру: если на сервере включена интеграция температуры или сезонов, используйте /hdtemperature, чтобы увидеть источники и вклад каждого из них.

/hdhelp показывает в игре все команды и аргументы. Нажатие на пункт помощи только вставляет текст в чат и не выполняет команду.

04Без OP и частые вопросы

Что доступно без OP?/headiet для своей панели, /hdinfo для еды, /hdtemperature для отчёта о температуре, /hdhelp для справки. Для редактирования правил сервера нужны права администратора.
Можно ли редактировать еду в просмотрщике?Нет. Просмотрщик показывает снимок, предоставленный сервером; данные отображаются на локальной странице. Обновление страницы или вставка JSON не записываются обратно в игру.
Управляете сервером?Права команд, пути настроек, датапаки и границы перезагрузки описаны в руководстве администратора.
