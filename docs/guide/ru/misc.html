08 / UTILITIES

От заполнения жидкостью до взаимодействия с блоками — по фактическим настройкам.

Эта страница описывает отдельные малые функции и полезные инструменты; она показывает поддерживаемые модом входы и не означает, что в каждом мире настроены соответствующие предметы или блоки.

01Заполнение правым кликом по источнику жидкости

Сервер читает правила в config/healthy_diet/bottle_fills.json: при совпадающем предмете в руке правый клик по блоку-источнику указанной жидкости расходует один исходный предмет и выдаёт настроенный результат; результат может содержать NBT.

Это не «автоматическое наполнение всех бутылок». Конкретные предметы, жидкости и результаты зависят от настроек сервера; в творческом режиме предмет не расходуется и результат не создаётся сам.

Правило по умолчанию новой установки

Файл по умолчанию превращает minecraft:glass_bottle + источник minecraft:water в minecraft:potion с NBT зелья воды. В режиме выживания одна пустая бутылка заменяется результатом; если в руке стак, результат сначала попадает в инвентарь, а при заполнении выпадает. Изменённые файлы сервера не подчиняются этому примеру; текущая жидкость тоже не совпадает с блоком-источником.

Источник: BottleFillConfig, BottleFillHandler.onRightClickBlock.

02Туман под водой и в лаве по эффекту

Клиент читает config/healthy_diet/fog_effects.json; при наличии настроенного эффекта зелья можно изменить начало/конец тумана под водой и конец тумана в лаве. Эффект по умолчанию — ночное зрение; конкретные расстояния настраиваются в клиентском файле.

Меняется расстояние тумана, а не цвет всего тумана. При окончании эффекта расстояние плавно возвращается к исходному. Перезагрузка сервера не заменяет чтение локального файла тумана каждым клиентом.

Поля файла по умолчанию

Локальные значения новой установки: эффект minecraft:night_vision, waterFogStart=80, waterFogEnd=160, lavaFogEnd=6 (в блоках); если совпадает хотя бы один эффект из списка, используется этот набор расстояний, при нескольких совпадениях — первый по порядку. Выдача эффекта игроку сервером не означает синхронизацию локального файла тумана.

Источник: FogEffectConfig, FogRendererMixin.

03Правый клик по блокам и размещённая еда

Датапак data/<пространство имён>/healthy_diet/blocks/<путь блока>.json определяет варианты правого клика: совпадение состояния блока, предмета в основной руке и приседания, а также изменение питания, эффекты зелий, команды, расход, кулдаун и отмену ванильного взаимодействия.

Эти правила выполняются на сервере; для ненастроенных блоков они не применяются автоматически. Для торта и другой еды, которую едят по кускам, питание рассчитывается за фактически съеденный кусок, а не за весь блок каждый раз. Размещённая еда со сроком годности по-прежнему использует мировое время.

Что может одно правило

В одном файле блока можно описать несколько вариантов: например, срабатывание только при hand=item и совпадении предмета в основной руке со списком items; sneak=require требует приседания. consumeItem задаёт расход за раз, cooldownTicks по умолчанию 20; в командах можно ссылаться на координаты блока {x}, {y}, {z}. Это примеры полей, а не заданные правила блоков с этого сайта.

Текущий вход: ведите правила блоков через датапак и перезагружайте сервер; визуальное редактирование блоков в главном меню /hdui не описывается как завершённая возможность.
Источник: BlockConfig, BlockInteractEvents, ConfigManager.loadBlockConfigsFromPacks.

04Часто используемые вспомогательные команды

КомандаНазначение и границы
/hdcloneitemOP4. Частично перезаписывает соответствующие записи основной руки настройками из второй руки; отсутствующие группы сохраняются, полной очистки и пересоздания нет.
/cleartoast [игрок]Для себя OP не нужен, для указанного игрока — OP2; очищает очередь достижений клиента, а не экран TitlePro.
/hdhelpДоступна всем; команды по группам, описание по наведению; нажатие только вставляет текст в чат и не выполняет команду.
/hdtemperatureДоступна всем, без аргументов; показывает источники и разбивку температуры в текущей позиции исполнителя, подробности по наведению; источники зависят от интеграций.

При использовании /hdcloneitem положите источник настроек во вторую руку, цель — в основную; команда перезаписывает только реально настроенные группы источника, остальные группы цели сохраняются, качество, редкость и примечания варианта цели также не копируются. Чтобы посмотреть аргументы и права, введите /hdhelp в чат и наведите на строку; нажатие на команду только вставляет текст и не выполняет её.

У команд разные права и аргументы; изменение настроек, подробные описания и входы перезагрузки описаны в руководстве администратора.

Источник: HDCloneItemCommand, HDClearToastCommand, HDHelpCommand, HDTemperatureCommand.
