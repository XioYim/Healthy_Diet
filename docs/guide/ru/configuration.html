01Файлы, владельцы и обновление

Если не указано иное, пути указаны относительно config/healthy_diet/. Записи датапака находятся в data/<пространство имён>/healthy_diet/. Фильтр работает по файлу, области и полю.

02server.json: разделы сервера

Один файл содержит разделы gameplay, privacy, shelfMerge. Старые отдельные файлы переносятся сюда и в migration_backup/.

ПолеПо умолчаниюПоведение
shelfTemperatureEnabledfalseГлавный переключатель срока годности и температуры. Выкл. приостанавливает порчу, температуру/свежесть, продукты и команды истечения, отказ по температуре, эффекты зон и связанные строки подсказки; данные предметов сохраняются, простой не начисляется задним числом.
lsoIntegrationEnabledtrueРазрешает hd:shelf читать полную среду LSO; не отключает остальную совместимость LSO.
ecIntegrationEnabledtrueРазрешает напрямую использовать климат EC и сезонные множители HD, не меняя данные EC от LSO.
proxyHeatstrokeEffecttrueСервер раз в 5 секунд зеркалит тепловой удар LSO в тепловой удар EC для размытия и снимает при отсутствии источника/иммунитете.
bonusUpdateTicks100Интервал обновления бонусов атрибутов (1–1 728 000 tick, около 5 секунд).
effectUpdateTicks200Интервал обновления бонусов зелий (1–1 728 000 tick, около 10 секунд).
ejectIllegalProtectedItemsfalseЕсли у недоверенного держателя защищённый предмет: true выбрасывает под ноги, false замораживает и предупреждает. По умолчанию false, чтобы не терять предметы при ошибке классификации.
removeOwnerOnDeathDropfalsetrue снимает защиту со всех выпавших при смерти; false ставит UUID умершего только на предметы без владельца и сохраняет существующих.
debugLogsfalseСерверные диагностические логи правого клика и размещённой еды; перечитать /hdreload, после проверки отключить.
privacy.sendCommandTextToAllPlayersfalseПо умолчанию текст команд этапа получает только OP4; true отправляет полную настройку этапа игрокам без OP, не меняя права выполнения.
shelfMerge.mergeRemainingMinutes5Максимальная разница оставшегося времени для стака (1–1 440 минут).
shelfMerge.mergeTempThreshold10.0Максимальная разница температуры для стака (0–100℃); NaN игнорируется.
shelfMerge.mergeColdFreshThreshold20.0Максимальная разница холодной свежести для стака (0–100).
Игровой экран OP сохраняет только gameplay. privacy и shelfMerge редактируются на диске, затем /hdreload. Файл только для чтения приводит к ошибке сохранения без изменения авторитетных значений в памяти.

03display.json: локальные настройки клиента

Локальное оформление и значения редактирования не участвуют в синхронизации игровых правил сервера. Правила сервера находятся в server.json → gameplay.

ПолеПо умолчаниюПоведение
nutritionPerLine6Максимум обычных строк питания/условий, затем многоточие; 1 означает только первую запись, а не одну на строку (1–100).
titleproWrapWidth1000Ширина переноса заголовка TitlePro в пикселях (1–100 000).
defaultConditionalGainEnabledtrueНачальный выбор «фактического прироста» для нового черновика условия, не переключатель сохранённых правил.
infoGapWidth20Фиксированный зазор между текстом и правым содержимым в режиме D (0–100 000).
maxInfoWidth320Максимальная ширина информационной панели D; подробности S не ограничены (0–100 000).
showUnifiedPotionStylefalseГлавный переключатель стиля зелий; false обходит выбор предмета и принудительное объединение.
enableEnchantmentInfotrueАвтоматически показывать описание книги зачарований в D при наличии ключей перевода.
enablePotionInfotrueУправляет блоком ванильных/HD/внешних эффектов, объединённых атрибутов и жажды LSO в D; обычные эффекты, зоны, JEI/свой текст и описания зачарований остаются.
hideSystemPrefixesfalseСкрывает только префиксы и пробелы строк HD, не пользовательские имена, разделители и сегменты.
temperatureUnitcelsiuscelsius или fahrenheit для подсказок/HUD клиента; сохранённые настройки и редакторы остаются в Цельсиях; недопустимое значение — Цельсий.
temperatureUnitChosenfalseВыбрал ли клиент единицу явно; локальное состояние первого запуска.
groupLocalizePromptedfalseЛокальное состояние запроса OP о переводе стандартных имён групп; не общая настройка.
defaultEffectsShiftOnlyfalseНачальная видимость новой строки зелья: всегда или только Shift; существующие строки сохраняют свой выбор.
defaultForceUnifyfalseНачальное принудительное объединение новых строк эффектов; только если у предмета уже есть подсказка/запись датапака.
defaultFoodBarDisplayModealwaysalways / shift / info / off. off возвращается к ванильным строкам пищевой ценности; влияет на ненастроенные предметы и новые строки.

Устаревшие смещения/ширина панели и поля тени текста в этом файле не используются. _note_* — справка только для чтения. Сохранение на экране клиента применяется сразу; после ручной правки перезапустите клиент.

04Датапак питания: группы, этапы и бонусы

Пути в data/<пространство имён>/healthy_diet/: nutrition_groups/<groupId>.json (одно определение), nutrition_stages/<groupId>.json (этапы + hideAutoBonus), nutrition_bonuses/<groupId>.json (примечание + бонусы). Оверлей HD — в config/healthy_diet/datapack/, имена файлов — ID групп. Максимум 64 группы.

Поля группы

ПолеПо умолчаниюОписание

nutritionSymbolΨ Префикс строки питания; пусто — значение по умолчанию с пробелом.
order0Порядок по возрастанию; при равенстве — по ID группы.
color / colorStyle#FFFFFF / nullHEX-цвет или ключ схемы. style управляет dynamic/nameStyle/speed/steps/waveStep/pulseDelay/reversals/bold/italic/underlined для схем; для сплошного цвета игнорируется.
decayRate6.0Каждый потраченный пункт голода снижает питание на 1/decayRate; неположительное отключает естественное снижение.
iconemptyНеобязательный ресурс иконки; пусто — запасной вариант UI.
initialValue0Начальное значение новой группы/игрока, 0–100.
gainMultiplier1Множитель положительных и отрицательных изменений; 0 допустим; отрицательное/нечисловое — 1; итог ограничен 0–100.

nutritionTipColorsgeneratedЧетыре слота: обычный/условный × прирост/потеря; настройка решает, следует ли прирост за цветом имени группы.

Поля этапов и бонусов

ПолеПо умолчаниюОписание

05Предметы, подсказки, блоки и качество

Каталоги датапака: items/<itemPath>.json, tooltips/<itemPath>.json, blocks/<blockPath>.json, quality_levels/<id>.json, rarities/<id>.json, effect_lines/<effectId>.json. Предметы/подсказки поддерживают .json.disabled, блоки — нет. Стиль строки эффекта переопределяет предмет только при включённом принудительном объединении.

Группы полей предмета

ПолеЗначение
nutritionID группы → изменение еды, умножается на множитель группы, пожизненный коэффициент и число порций.
effectsЗелья после еды: уровень, tick, вероятность, частицы, необязательная кривая свежести.
foodCooldownКраткие maxUses, cooldownCount, cooldownMinutes, restoreHunger.
foodFatigueПожизненные lossStart и aversionCount; линейное снижение только при обоих.
shelfБазовое время, температурные кривые, множители измерений, свежесть/холод, температура среды, эффекты еды.
onEatCommands / suppressEffectsКоманды еды и удаление собственных эффектов, у каждого своя задержка.
conditionalRulesУсловия питания → изменения цели, команды и подсказки, сохраняются целыми правилами.

06Поля срока годности и температуры

Значения shelf предмета отличаются от сезонных и средовых файлов в shelf_life/ и temperature/. Значения по умолчанию применяются к новой конфигурации; встроенная еда может их переопределять.

resultItem / inheritTemperatureOnExpireminecraft:air / trueair — исчезновение; другой результат наследует только температуру, а не прогресс срока.
expireCommandemptyВыполняется от держателя при истечении в руке, не в контейнере/на земле.

temperatureCurves[]До 16 кривых температура→порча с линейными концами и внешними буферами.
dimensionDecayMultipliers{}ID измерения → множитель; не указанные — ×1.
schemehd:shelf_enID схемы отображения; старый hd:shelf нормализуется к текущей схеме.
coldRetention / coldRecoveryRate / coldDegradationRatefalse / 1 / 15Включить восстановление при полной заморозке; минут за минуту 0–100; постоянное снижение предела за шаг 1–100% базового времени.
temperatureEffectCurves[]До 20 эффектов температурных зон при еде, независимо от кривых порчи.
common.minTemperatureC / maxTemperatureC / initialTemperatureC-30 / 100 / 10Абсолютные границы и начальная температура; встроенная еда может переопределить.

common.coldFreshStartC / freezingStartC / fullyFrozenC3 / -5 / -20Пороги холодной свежести и заморозки.
common.highTemperatureC / preservationRate30 / 0.8Начало горячей зоны и защита при 50% свежести.
naturalEnvironment.temperatureChangeC / temperatureChangeMinutes1 / 2Базовая среда: по умолчанию 1℃ за 2 минуты.

08Схемы интерфейса настроек

Меню настроек (/hdconfig)

/hdconfig — локальная команда клиента, сама проверяет OP4. Игрок без OP может войти в локальное оформление с других экранов, но не выполнить команду. Макеты только для чтения и не получают реальные значения.

Игровые правила сервера · девять пунктов

Интеграции температуры · пять таблиц + отдельный LSO

Пять вкладок таблиц используют один черновик и одно проверенное сохранение; при переключении несохранённые изменения сохраняются. Шестая открывает отдельную форму. Вкладки ниже только поясняют группы файлов и не меняют данные.

Множители порчи

Множитель 0–100 по ID сезона; по умолчанию ×1; нужен активный сезон EC и включённая интеграция EC. Старые шесть сезонов остаются шестью записями.

Тепло блоков

Поиск по имени/ID блока; + нагревает, − охлаждает, −1000–1000. Состояния могут иметь отдельные правила; тепло, расстояние и перекрытие определяют вклад.

День/ночь

Смещения полудня/полуночи по сезонам, каждое −100–100℃ (по умолчанию 0), интерполируются в течение дня; приоритет у границ биома.

Сезонная температура

Дополнительные −100–100℃ по сезонам (по умолчанию 0) поверх климата EC; без EC используется первый сезон.

Дождь/снег

Дождь/снег по умолчанию −1℃, гроза −2℃ по сезонам, оба −100–100℃; гроза не добавляет обычный дождь.

Температура мира LSO

Отдельная форма измерения, не входит в общее сохранение пяти таблиц; значения используют единицы LSO, не Цельсий.

Порядок сезонов: начало весны, дожди, пробуждение насекомых, весеннее равноденствие, ясно, дождь зерна, начало лета, полное зерно, колошение, летнее солнцестояние, малая жара, большая жара, начало осени, конец жары, белая роса, осеннее равноденствие, холодная роса, иней, начало зимы, малый снег, большой снег, зимнее солнцестояние, малый холод, большой холод. Просмотр не загружает реальные 24 записи сервера.
