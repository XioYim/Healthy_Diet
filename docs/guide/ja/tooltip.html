05 / TOOLTIP

通常ツールチップと S/D 詳細は役割が異なる。

アイテムのホバーツールチップは情報行を並べ替えられます。プレイヤーは画面内の表示キーを押して異なる詳細を確認でき、サーバー管理者は項目ごとに表示を設定できます。

アイテムツールチップレイアウトマーカーS / D モード
キーの前提：S、D はデフォルトではインベントリなどの画面を開き、マウスをアイテムに合わせているときのみ使えます。これらのキーはクライアントで再割り当てできます。Web ページのシミュレーションは各モードの情報カテゴリを示すだけで、特定のアイテムにすべての行があるとは限りません。

01通常、S、D モード

通常ホバーアイテム名と常時表示に設定された行を表示します。実際には Shift や全体表示ルールの影響も受けます。
S を押す保存期間、栄養、食べ飽きなどの詳細を確認します。具体的な項目には対応する食べ物設定と情報行が必要です。
D を押す説明情報ブロック、JEI 情報、ポーション効果、カスタム infoOnly テキストを表示します。
選択は Web ページの説明だけを変え、ゲームやサーバーのアイテム設定を読み取ることはありません。

S と D を同時に押した場合、後から押したキーが優先されます。同じクライアント tick で同時に押した場合は D が優先されます。H は栄養パネル、I は TitlePro エディターを開くゲーム内キーで、S/D 詳細キーではありません。

インベントリで試す

まずサーバーで実際に栄養や保存期間が設定されている食べ物にカーソルを合わせ、通常ホバーと S を押した状態を比較します。次に説明や効果情報があるアイテムで D を押します。対応する内容がない行やサーバー管理者が隠した行は、キーを押しても表示されません。S と D で2ページの内容が統合されることもありません。

ソース根拠：HealthyDietKeys、TooltipHandler。

02ツールチップの行配置

アイテムツールチップの追加行はリスト順に描画されます。特殊マーカー行は挿入位置であり、固定テキストを1行書く必要はありません。

行マーカー表示される情報
栄養 / 食べ飽き栄養取得とクールダウン/食物嫌悪の情報
保存期間 / 品質アイテムの保存期間状態と品質表示
ポーション効果設定効果とアイテム固有効果など
説明 / JEID モードの情報ブロックと説明内容
飲食値満腹度と統合された飲食データ

通常のテキスト行は Shift 専用または詳細モード専用にできます。名前行と通常の追加行ではルールが異なります。あるアイテムに対応する設定や内容がない場合、すべての行が表示されるとは限りません。

レイアウトの考え方

栄養情報を前に出したい場合は、栄養マーカーを追加行リストの前部に置きます。サーバー管理者の説明を詳細ページに残したい場合は、自作テキスト行に infoOnly を設定します。マーカーは位置決めを担当し、設定内容を生成するわけではありません。shiftOnly は追加行だけを制御し、Shift を押していないときにアイテム名を消すことはできません。

ソース根拠：TooltipLineConfig の nutritionMarker、cooldownMarker、shelfLifeMarker、effectsMarker、foodBarMarker などのフィールド。

03アイテムごとの表示設定

ツールチップ設定パネルには、全体クリア、説明情報、栄養、食べ飽き、保存期間、ポーション効果、飲食値などのスイッチがあります。スイッチは表示に影響するだけで、食べ物に既に設定された栄養や保存期間の設定を自動削除しません。

非表示とクリアの違い

たとえば保存期間行をプレイヤーに見せたくない場合、「保存期間」の表示スイッチを調整すればよく、保存計算に影響するアイテム設定を削除する必要はありません。「全体クリア」は他の MOD やバニラが追加した通常のツールチップ行を消すためのもので、Healthy Diet が生成する品質、保存期間、栄養などの行を削除するものではありません。HD の行を隠す場合は対応するスイッチを個別に設定してください。

NBT バリアントの制限：説明情報と効果行の一部のスイッチはアイテムレベルの設定で、バリアントページではロックされます。共通設定に戻って調整してください。その他のスイッチは、そのアイテムやバリアントに実際にデータがあるかどうかで判断します。
ソース根拠：TooltipVisibilitySettingsScreen.init の7行ボタンと itemLevelLocked。

04編集入口と D ページのソース

サーバー管理者がアイテムを持って /hdui tooltip (OP4) を実行します。設定済みの NBT バリアントがある場合はアイテムメインメニューに入り、共通エントリまたはバリアントを選んでからツールチップを開きます。バリアントがない場合はアイテムレベルの共通ツールチップエディターを直接開きます。D ページの情報ブロックはバニラ説明、JEI、HD 設定、効果を集約できます。ユーザーが書いた行がある場合、実際のレイアウトと上書き優先度でテキストと位置が決まります。

右 Ctrl は関連効果詳細のデフォルトキーとして使えますが、その具体的な表示はインストールされている JEED/JEI 関連コンポーネントとキー設定に依存します。このキーをすべての環境に存在する固定の独立ページとして説明しないでください。

別のアイテムの先頭行の配色スキームと動的パラメータだけを複製したい場合は、/hdset tooltip 配色複製 (OP2) を使用できます。セグメントテキストはエディターでセグメントごとに調整する必要があり、このコマンドでテキストを複製することはできません。

ソース根拠：TooltipHandler の D 情報ブロック構築、HDUICommand、HealthyDietKeys.JEED_EFFECT_PAGE。
関連する外観ツールチップテキストのグラデーションスキームと動的スタイルは表示内容とは独立しています。
