01プレイを始める

  • 1一致するファイルをインストール：Minecraft のバージョンとローダーに合った Healthy Diet ファイルを使用してください。マルチサーバーでは両側の互換性が必要です。
  • 2栄養パネルを開く：/headiet を入力し、自分の栄養グループと現在値を確認します。
  • 3食べ物を確認：食べ物を持って /hdinfo を入力すると、一致するバリアントのサーバー設定を確認し、ローカルのフードクエリビューアを開きます。/hdinfo minecraft:apple で指定アイテムのデフォルトスタックを確認することもできます。
  • 4ツールチップを見る：アイテムツールチップには栄養、繰り返し摂取、保存期間の情報を表示できます。どの行を常時表示し、どれを Shift で展開するかはサーバー管理者が決めます。
  • 5温度を診断：サーバーで温度や季節の連動が有効な場合、/hdtemperature で現在のソースと各貢献を確認できます。

/hdhelp でゲーム内の全コマンドと引数を確認できます。ヘルプ項目をクリックしてもチャット入力欄に入るだけで、自動実行はされません。

02ゲームプレイ概要

栄養新しい設定では通常、乳製品、果物、穀物、タンパク質、糖分、野菜の6グループがあります。食べ物は複数グループに同時に影響でき、グループ値は設定に従って減少します。ステージやグループ横断条件でボーナスが得られます。栄養値を読む →
繰り返し摂取短期的な食べ飽きは、同じ食べ物を短時間に繰り返し食べることを制限します。長期的な食物嫌悪は累計摂取記録に応じて利益を弱めます。どちらも食べ物ごとの設定です。食べ飽きを読む →
保存期間保存期間が設定された食べ物は残り時間を記録します。環境、季節、冷蔵庫、ディメンション倍率、カスタム温度帯が保存と期限切れの結果に影響します。保存期間を読む →
すべての食べ物が同じルールで制限されるとは限りません：ある食べ物に食べ飽き、保存期間、効果が設定されていなければ、対応する挙動が勝手に発生することはありません。具体的にはサーバーとアイテム設定に準拠します。

03表示と確認

ツールチップと詳細モード通常、S、D モードで表示内容が異なります。常時表示行と Shift 行はアイテムのレイアウトと表示スイッチで決まります。ツールチップを読む →
品質、レアリティ、表示装飾品質 ID、レアリティ表示、グラデーション、動的スタイル、専用ツールチップ配色。品質を読む → · 表示装飾 →
TitlePro同じ MOD に付属する画面テキストシステムで、タイトル、テーブル、色オーバーレイを表示できます。摂取の前提条件ではありません。TitlePro を読む →
フードクエリビューア独立した単一ファイルページで、内蔵例を表示したり、自分の /hdinfo JSON を貼り付けたりできます。読み取り専用で、ゲームへの書き戻しはありません。クエリビューアを開く →

04OP なしでできることとよくある質問

OP なしで何が使えますか？/headiet で自分の栄養パネル、/hdinfo で食べ物、/hdtemperature で温度レポート、/hdhelp でヘルプを確認できます。サーバールールの編集には管理者権限が必要です。
クエリビューアで食べ物を直接編集できますか？できません。クエリビューアはサーバーが提供するスナップショットを表示し、データはローカルページ上に表示されます。更新や JSON の貼り付けでゲームに書き戻されることはありません。
サーバーを管理しますか？コマンド権限、設定パス、データパック、リロードの境界はサーバー管理者マニュアルを参照してください。
