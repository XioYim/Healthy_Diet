HEALTHY DIET / FEATURE GUIDE

Healthy Diet 機能ガイド。

栄養、食べ飽き、品質、保存期間、ツールチップ、表示装飾、TitlePro、便利機能、サーバー設定を機能ごとに解説します。各ページでは例、デフォルト設定、サーバー実際のルールの境界を明記します。

MAP章マップ

00 / INTRODUCTION

導入とインストール

3つの基本ルール、インストールと互換性、デモ動画とプロジェクトページ。

まずこのページを読む → 00 / QUICK START

プレイヤー入門

3つの確認コマンド、ゲームプレイ概要、表示と確認、よくある質問。

コマンドから始める → 01 / NUTRITION

栄養値

6つの栄養グループ、数値と減少、ステージ、ボーナス、条件ルール、NBT バリアント、管理コマンド。

ルールとパネル例を見る → 02 / FATIGUE

食べ飽き

短期クールダウン、回復条件、永続的な栄養減少。例の回数を調整できます。

初版を見る → 03 / QUALITY

品質、レアリティ、アイテム登録

品質 ID、レアリティ表示、新規アイテム登録の境界と反映タイミング。

初版を見る → 04 / SHELF LIFE

保存期間

基本時間、温度曲線、保冷、摂取効果、マルチサーバーでの計算。

初版を見る → 05 / TOOLTIP

ツールチップと詳細モード

表示行の配置、表示スイッチ、通常・S・D モードの内容の違い。

初版を見る → 06 / APPEARANCE

グラデーションと表示装飾

グラデーションスキーム、動的スタイル、単色パレット、専用ツールチップ配色のパス。

初版を見る → 07 / TITLEPRO

TitlePro と摂取効果

タイトルエディター、コマンド、摂取時のポーション効果、アイテムコマンド。

初版を見る → 08 / MISC

小機能集

液体の詰め替え、霧の距離、ブロック右クリックルール、便利コマンド。

初版を見る → 09 / ADMIN

サーバー管理者マニュアル

現在の設定パス、データパックのオーバーレイ、リロードとクライアント同期の境界。

初版を見る →
