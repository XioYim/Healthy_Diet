00 / INTRODUCTION

Healthy Diet が何を変えるかを知る。

この MOD は「食事」を満腹度だけでなく、栄養構造、食べ飽きによる制限、設定可能な保存期間という3層のルールに拡張します。サーバー管理者が内容を定義し、プレイヤーはゲーム内で結果を確認します。

01互いにつながる3つのルール

栄養グループとステージ食べ物はサーバー管理者が定義した栄養グループを供給します。複数のグループを設定範囲内に保つと、ステージ、属性修飾、ポーション効果のボーナスが発動します。グループ、しきい値、効果はすべて設定可能です。
食べ飽きと食物嫌悪短期間の繰り返し摂取でクールダウンと回復制限が発生します。長期的な累計摂取記録により、特定の食べ物の効果が永続的に弱まります。ルールは食べ物ごとに設定され、すべての食べ物でデフォルト有効ではありません。
保存期間と温度保存期間が設定された食べ物は残り時間を記録します。環境温度、季節、冷蔵庫、ディメンション倍率が劣化に影響し、期限切れの結果はアイテム設定で決まります。

ほかに栄養パネル、アイテムツールチップ、品質とレアリティ、グラデーション、TitlePro タイトル、ローカルフードクエリビューアがあり、これらのルールをサーバー上で読める・確認できるようにします。

詳しい仕組みは 栄養値、食べ飽き、保存期間 を参照してください。
