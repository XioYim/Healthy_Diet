HEALTHY DIET / FEATURE GUIDE

Healthy Diet 功能指南。

按功能阅读营养、食物厌倦、品质、保质期、Tooltip、显示美化、TitlePro、实用功能和服主配置。每页注明示例、默认配置与服务器实际规则的边界。

按当前源码整理 中文先行 不写死版本与数量 关键章节可交互
先说明范围：本指南介绍模组提供的能力，不代表每个服务器都启用同一套数值。营养组、阶段阈值、命令、效果、保质期参数等均以你所在服务器和实际安装文件为准。

START先看这里

想先上手 从「营养值」开始：它决定吃什么、阶段怎么变化，也是后续条件规则与联动加成的基础。
想查规则 按「机制概览 → 增加与衰减 → 阶段 → 条件规则」的顺序阅读；每节先给结论，再说明配置边界。
想查配置 服主配置、命令、数据包和同步规则集中在「服主手册」；公开页面不写死内部版本号。
阅读原则：页面里的数字若标注“示例”，只用于解释机制；没有标注的数字来自当前源码默认值，仍可能被服务器覆盖。两者都不会冒充你所在世界的实际规则。
