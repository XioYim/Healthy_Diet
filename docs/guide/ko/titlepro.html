07 / TITLEPRO & EFFECTS

타이틀 표시와 섭취 효과는 두 가지 설정 경로입니다.

TitlePro는 화면의 타이틀, 표, 오버레이를 설정합니다. 음식 편집기의 효과, 명령어, 효과 제거는 음식을 먹은 뒤 각각 처리됩니다.

01I 키로 타이틀 편집기 열기

게임 안에서 I를 누르면 TitlePro 편집기가 열립니다. 이미 화면이 열려 있으면 게임 내 단축키에 반응하지 않습니다. 편집기는 타이틀의 텍스트, 위치, 애니메이션, 배경, 스킴/템플릿을 나누어 편집합니다.

텍스트와 기본 설정내용, 레이아웃, 좌표, 크기, 유지 시간, 페이드 인/아웃 등 기본 매개변수를 편집합니다.
애니메이션과 배경진입/퇴장 애니메이션, 배경색, 투명도, 여백, 기타 스타일을 조정합니다.
스킴과 템플릿스킴은 타이틀 텍스트를 저장하지 않고 레이아웃만 저장합니다. 템플릿은 타이틀 전체를 저장합니다. 재사용 전에 어느 것을 선택했는지 확인하세요.
스킴인가 템플릿인가?

위치, 애니메이션, 배경 등 레이아웃을 재사용하고 다른 텍스트를 쓰려면 스킴을 선택합니다. 텍스트를 포함한 타이틀 전체를 재사용하려면 템플릿을 저장합니다. 파일은 각각 로컬 config/healthy_diet/titlepro/titlepro_schemes/와 config/healthy_diet/titlepro/titlepro_templates/에 있습니다. 템플릿을 보내기 전에 명령어를 실행하는 인스턴스에 해당 파일이 있는지 확인하세요.

소스 근거: HealthyDietKeys.OPEN_TITLEPRO, TitleTextEditScreen, TitleBasicSettingsScreen, TitleAnimSettingsScreen, TitleBgSettingsScreen.

02서버 타이틀 명령어

아래 5개 명령어는 모두 OP2가 필요합니다. 대상은 플레이어 이름 또는 플레이어 선택자입니다. 인자 문자열은 TitlePro/표가 각각 해석합니다. 세부 옵션과 자동 완성은 게임 내 /hdhelp로 확인하세요.

명령어 (모두 OP2)용도와 필수 인자
/titlepro <targets> <args...>타이틀 텍스트와 레이아웃 인자를 해석해 대상 플레이어에게 보냅니다. 추가 명령어가 활성화된 경우 명령어 소스로 실행될 수도 있습니다.
/titleprosend <targets> <templateName>실행 인스턴스에 저장된 타이틀 템플릿 전체를 불러와 보냅니다. 템플릿의 추가 명령어도 실행될 수 있습니다.
/titletable <targets> <args...>표 타이틀 인자를 해석해 대상 화면으로 보냅니다.
/titleproclear <targets>대상 화면의 타이틀, 표, 오버레이를 지웁니다.
/titlescreen <targets> <#color> <alpha%> <stay_s> <fadeIn_s> <fadeOut_s>오버레이를 표시합니다. 투명도 0–100%, 세 시간 값은 음수가 아닌 초입니다.
사용 예시

/titlepro @s Hello 0 0 1 2 1 1 14 up

여기서 @s는 현재 명령어 소스, Hello는 텍스트, 이어서 X/Y 오프셋, 크기, 유지 초, 페이드 인/아웃 초, 줄 간격, 스택 방향입니다. 공백이 있는 텍스트는 따옴표로 감쌉니다. 서버에 저장된 템플릿이 있으면 /titleprosend @s <템플릿 이름>로 자신에게 보낼 수 있고 화면을 지우려면 /titleproclear @s를 사용합니다. 명령어의 숫자는 구문 예시이며 서버 기본 표시 효과가 아닙니다.

소스 근거: TitleProCommand, TitleProSendCommand, TitleTableCommand, TitleClearCommand, ScreenOverlayCommand.

03섭취 물약 효과

손에 든 아이템의 /hdui 편집기 '물약 효과' 페이지에서 설정하는 것은 음식을 먹은 뒤의 단발 효과입니다. 고정 효과 또는 보존 기간 신선도에 따라 변하는 곡선 효과를 추가할 수 있습니다. 이는 영양 그룹 단계 조건으로 지속 발동하는 독립 보너스 페이지와 다른 설정입니다. 각 효과에는 물약 ID, 레벨, 지속 tick, 입자 표시, 확률 등의 필드가 있습니다. 효과 지연은 아이템 설정의 effectDelay로 제어합니다.

계량 설명: 설정 내 효과 레벨은 0부터 시작하며 0은 게임의 I 레벨에 해당합니다. 지속 시간은 tick으로 저장되고 20 tick은 약 1초입니다. 각 효과의 probability=100은 반드시 발동을 시도한다는 뜻입니다. 신선도 곡선이 없으면 고정 레벨과 지속 시간을 사용하고 설정된 곡선은 해당 아이템에 필요한 보존 기간 상태가 있을 때만 레벨/시간을 바꿉니다.

아이템의 effectDelay 기본값은 10 tick(약 0.5초)입니다. 섭취 명령어나 '효과 제거' 페이지의 지연을 제어하지 않으므로 섭취 전체의 통합 지연으로 혼동하지 마세요.

소스 근거: ItemConfig.EffectEntry, EffectFreshnessCurve, ItemConfigEditScreenV2.

04섭취 명령어, 알림, 효과 제거

'명령어' 페이지는 onEatCommands를 관리합니다. 현재 화면에는 일반 명령어 추가와 Tellraw 구성 진입점이 있으며 구식 TitlePro 타이틀 생성 버튼은 없습니다. 영양 변화 알림에는 그룹별 독립 스위치가 있고 구 onEatTitles를 실행 중인 아이템 설정으로 보지 마세요.

'효과 제거' 페이지는 suppressEffects를 관리하며 섭취 후 지정한 아이템 고유 효과를 제거합니다. 기존의 제거 가능한 효과를 스캔할 수도 있습니다. 명령어, 물약 부여, 고유 효과 제거에는 각각 지연 설정이 있고 실제 실행은 서버 측입니다.

세 가지 지연을 혼동하지 마세요

onEatCommandDelay는 섭취 명령어, effectDelay는 설정된 물약 효과, suppressEffectDelay는 아이템 고유 효과 제거에 작용합니다. 새 아이템 설정에서 셋 다 기본 10 tick입니다. suppressEffects에 입력하는 것은 제거할 효과 ID이며 '플레이어의 모든 효과를 제거하는' 전역 스위치가 아닙니다.

소스 근거: ItemConfig.onEatCommands, suppressEffects, nutritionTitleEnabledByGroup, ItemConfigEditScreenV2의 명령어/효과 제거 페이지.
