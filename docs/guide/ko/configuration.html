01파일, 소유자, 업데이트

별도 표기가 없으면 경로는 config/healthy_diet/ 기준 상대 경로입니다. 데이터팩 항목은 data/<네임스페이스>/healthy_diet/에 있습니다. 파일, 범위, 필드로 필터할 수 있습니다.

파일 / 디렉터리범위역할일반적인 업데이트
server.json서버 권위게임 규칙, 개인정보, 보존 기간 스택 병합, 테스트 로그OP 게임플레이 화면 또는 /hdreload
display.json로컬 클라이언트툴팁 레이아웃, 온도 단위, 기본 표시 모드클라이언트 화면에서 저장. 수동 편집 후 클라이언트 재시작
colors/color_schemes.json양쪽 / 외형그룹, 품질, 툴팁, 스킴이 참조하는 이름 있는 그라데이션서버에서 /hdreload. 로컬 클라이언트 파일은 별도 재읽기
colors/solid_colors.json양쪽 / 외형편집기 색상 선택기용 팔레트서버에서 /hdreload. 클라이언트 로컬은 별도 업데이트
fatigue/fatigue_gradient.json외형음식 싫증/회복 줄의 색상과 애니메이션/hdreload
fatigue/fatigue_exempt.json서버 게임플레이다른 음식에 의한 회복 카운트에서 제외할 아이템 ID/hdreload
shelf_life/seasons.json서버 게임플레이계절별 부패 배율. Ecliptic Seasons 없을 때 폴백/hdreload
shelf_life/schemes/*.json동기화 표시보존 기간 템플릿, 색상, 계절 이름/hdreload 및 클라이언트에 스킴 전송
temperature/block_heat.json서버 게임플레이LSO 월드 온도 분기를 사용하지 않을 때의 블록 열 규칙/hdreload 또는 온도 화면 저장
temperature/weather_offsets.json서버 게임플레이24절기별 비/눈·뇌우 오프셋/hdreload 또는 온도 화면 저장
temperature/day_night_offsets.json서버 게임플레이24절기별 정오/자정 오프셋/hdreload 또는 온도 화면 저장
temperature/season_temperature.json서버 게임플레이절기별 추가 환경 온도 오프셋(EC 기후 위에 가산)/hdreload 또는 온도 화면 저장
bottle_fills.json서버 게임플레이액체 공급원 우클릭 소비와 출력/hdreload
fog_effects.json로컬 클라이언트설정 효과에 따른 수중/용암 안개 거리로컬 클라이언트 파일 재읽기. 서버 리로드 아님
item_rarities.json서버 / 동기화아이템 레벨 폴백 희귀도 ID/hdreload. /hdset rarity도 갱신
tooltip_templates.json편집기 로컬로컬 툴팁 줄 템플릿편집기가 로컬 인스턴스를 읽고 씀. 전역 클라이언트 동기화 아님
quality_registry/*.json시작 시 등록새 아이템 ID, 소스, 모델, 품질, 섭취 동작, 스택 한도ID 추가/삭제는 양쪽 재시작
datapack/data/<ns>/healthy_diet/월드 데이터팩 + HD 오버레이items / tooltips / blocks / nutrition_* / quality_levels / rarities / effect_lines월드 팩은 바닐라 /reload, HD 오버레이는 /hdreload
설정 JSON, 월드/HD 데이터팩, 시작 시 레지스트리 항목은 수명 주기가 다릅니다. 데이터팩 파일을 구 config/healthy_diet/items/에 복사해도 현재 아이템 정의가 되지 않습니다.

02server.json: 서버 권위 섹션

한 파일에 gameplay, privacy, shelfMerge 세 섹션이 있습니다. 구 별도 파일은 이 파일로 마이그레이션되고 migration_backup/으로 이동합니다.

필드새 파일 기본값동작
shelfTemperatureEnabledfalse보존 기간과 온도의 마스터 스위치. 끄면 부패, 온도/신선도, 만료 산물과 명령어, 온도 거부, 온도대 효과, 관련 툴팁 줄을 중지합니다. 기존 아이템 데이터는 유지되고 중지 기간은 소급 적용되지 않습니다.
lsoIntegrationEnabledtruehd:shelf가 LSO 월드 환경 전체를 읽도록 허용합니다. 다른 LSO 호환 기능을 비활성화하지 않습니다.
ecIntegrationEnabledtrueEC 기후와 HD 계절 부패 배율의 직접 사용을 허용합니다. LSO가 이미 제공하는 EC 데이터는 변경하지 않습니다.
proxyHeatstrokeEffecttrue서버가 5초마다 확인해 LSO 열사를 EC 열사로 미러링해 흐림 효과를 표시하고 소스가 없거나 면역이면 제거합니다.
bonusUpdateTicks100속성 보너스 갱신 간격(1–1,728,000 tick, 기본 약 5초).
effectUpdateTicks200물약 보너스 갱신 간격(1–1,728,000 tick, 기본 약 10초).
ejectIllegalProtectedItemsfalse미신뢰 소지자가 보호 아이템을 가질 때 true는 발밑에 드롭하고 false는 그 자리에서 동결하고 경고합니다. 기본값은 오분류로 인한 아이템 손실을 피합니다.
removeOwnerOnDeathDropfalsetrue는 모든 사망 드롭의 보호를 해제합니다. false는 원래 소유자가 없는 드롭에만 사망자 UUID를 설정하고 기존 소유자를 유지합니다.
debugLogsfalse블록 우클릭과 설치/분할 음식의 서버 진단 로그. /hdreload로 재읽기하고 문제 해결 후 비활성화하세요.
privacy.sendCommandTextToAllPlayersfalse기본적으로 OP4만 단계 명령어 텍스트를 받습니다. true는 실행 권한을 바꾸지 않고 전체 단계 설정을 비 OP 플레이어에게 보냅니다.
shelfMerge.mergeRemainingMinutes5스택을 허용하는 남은 시간 차 최대값(1–1,440분).
shelfMerge.mergeTempThreshold10.0스택을 허용하는 아이템 온도 차 최대값(0–100℃). NaN 차이는 무시됩니다.
shelfMerge.mergeColdFreshThreshold20.0스택을 허용하는 냉장 신선도 차 최대값(0–100).
게임 내 OP 서버 화면이 저장하는 것은 gameplay뿐입니다. privacy와 shelfMerge는 디스크에서 편집한 뒤 /hdreload하세요. 읽기 전용 파일이면 저장이 실패하고 메모리의 권위 값은 바뀌지 않습니다.

03display.json: 클라이언트 로컬 설정

로컬 외형과 편집 기본값은 서버 게임플레이 동기화 대상이 아닙니다. 서버 규칙은 server.json → gameplay에 있습니다.

필드새 파일 기본값동작
nutritionPerLine6일반 툴팁의 영양/조건 항목 최대 수. 초과하면 말줄임표로 자릅니다. 1은 첫 항목만이라는 뜻이며 한 줄에 하나가 아닙니다(1–100).
titleproWrapWidth1000TitlePro 타이틀 줄바꿈 폭(픽셀, 1–100,000).
defaultConditionalGainEnabledtrue새 조건 규칙 초안의 '실제 증가' 기본 선택. 저장된 규칙의 실행 스위치가 아닙니다.
infoGapWidth20D 모드에서 왼쪽 텍스트와 오른쪽 정렬 내용 사이 고정 여백(0–100,000).
maxInfoWidth320D 정보 패널 최대 폭. S 상세 보기는 이 제한을 받지 않습니다(0–100,000).
showUnifiedPotionStylefalse물약 스타일 마스터 스위치. false는 아이템과 기본 강제 통일 선택을 우회합니다.
enableEnchantmentInfotrue번역 키가 있으면 D 모드에서 마법 부여 책 설명을 자동 표시합니다.
enablePotionInfotrueD 모드의 바닐라/HD/외부 효과, 통합 속성, LSO 갈증 정보 블록을 제어합니다. 일반 압축 효과, 온도대 효과, JEI/사용자 지정 D 텍스트, 마법 부여 설명은 유지됩니다.
hideSystemPrefixesfalseHD가 생성하는 줄머리 기호와 여백만 숨깁니다. 사용자 지정 이름, 인라인 구분자, 세그먼트 텍스트는 숨기지 않습니다.
temperatureUnitcelsius이 클라이언트의 툴팁/HUD용 celsius 또는 fahrenheit. 저장 설정과 편집기는 섭씨 유지. 무효 값은 섭씨로 폴백.
temperatureUnitChosenfalse이 클라이언트가 온도 단위를 명시 선택했는지. 로컬 첫 실행 프롬프트 상태.
groupLocalizePromptedfalse내장 그룹 이름 번역에 관한 로컬 OP 프롬프트 상태. 공유 설정이 아닙니다.
defaultEffectsShiftOnlyfalse새 물약 줄 기본 표시: 항상 vs Shift 전용. 기존 줄은 자체 선택을 유지합니다.
defaultForceUnifyfalse새 효과 줄의 강제 통일 초기 선택. 아이템에 이미 툴팁 설정/데이터팩 항목이 있을 때만 적용.
defaultFoodBarDisplayModealwaysalways / shift / info / off. off는 바닐라 음식 값 줄로 폴백. 미설정 아이템과 새 줄에 영향을 줍니다.

폐기된 패널 오프셋/폭과 텍스트 그림자 필드는 이 파일에 포함되지 않습니다. _note_*는 읽기 전용 도움말입니다. 클라이언트 화면에서 저장하면 즉시 적용되고 수동 편집 후에는 해당 클라이언트를 재시작하세요.

04영양 데이터팩: 그룹, 단계, 보너스

data/<네임스페이스>/healthy_diet/ 아래는 nutrition_groups/<groupId>.json(그룹 정의 1개), nutrition_stages/<groupId>.json(단계 + hideAutoBonus), nutrition_bonuses/<groupId>.json(메모 + 보너스)입니다. HD 오버레이는 config/healthy_diet/datapack/에 두고 파일 이름은 그룹 ID입니다. 최대 64개 그룹.

그룹 필드

필드기본값설명
displayNameGroupUI/툴팁에 표시할 그룹 이름. 내장 기본값에는 로컬라이즈 이름이 있을 수 있습니다.
nutritionSymbolΨ 영양 줄 접두사. 비우면 기본값 + 공백으로 폴백.
order0오름차순 표시 순서. 같은 값은 그룹 ID로 결정.
color / colorStyle#FFFFFF / null16진수 단색 또는 스킴 키. style은 스킴의 dynamic/nameStyle/speed/steps/waveStep/pulseDelay/reversals/bold/italic/underlined를 제어하며 단색에서는 무시됩니다.
decayRate6.0소비한 허기 1포인트마다 영양을 1/decayRate만큼 줄입니다. 0 이하는 자연 감소를 비활성화.
iconempty선택적 아이템 아이콘 리소스. 비우면 UI 폴백.
initialValue0새 플레이어 또는 새로 추가한 그룹의 초기값, 0–100.
gainMultiplier1음식의 양/음 변화에 곱합니다. 0 허용. 음수/비유한 값은 1로 폴백. 최종 값은 0–100으로 클램프.
enabledtrue비활성화하면 모든 플레이어에서 숨기고 동결하며 감소, 조건, 보너스를 중지합니다.
requiredPlayerTagempty필요한 플레이어 스코어보드 태그(정확히 일치). 비우면 제한 없음. 아이템/블록 태그가 아닙니다.
requiredModIdempty필요한 로드된 서버 모드 ID. 비우면 제한 없음.
nutritionTipColorsgenerated4슬롯: 일반/조건 × 증가/감소. 사용자 지정은 증가가 그룹 이름 색상을 따르는지 제어합니다.

단계와 보너스 필드

필드기본값설명
stages[].min/max0/100양 끝을 포함하는 정수 경계. 판정 전에 현재 값을 반올림. 인접 단계는 겹치거나 비어서는 안 됩니다.
stages[].label/tooltip/commandsempty / [] / []선택적 제목, 추가 호버 줄, 설정된 단계 명령어. 명령어 텍스트는 privacy가 허용하지 않는 한 OP4에만 전송됩니다.
hideAutoBonusfalsetrue이면 이 그룹의 모든 단계 툴팁에서 자동 범위 제목과 보너스 미리보기를 숨깁니다.
remarkempty편집기 목록 라벨. 비우면 파일 이름. 계산에는 영향 없음.
bonuses[].conditions{}그룹 ID → {min,max}. 여러 조건은 AND.
bonuses[].attributeBonuses[][]attribute(기본 max_health), operation add/multiply_base/multiply_total(기본 add), value.
bonuses[].effectBonuses[][]effect ID, level(0=I), duration tick(기본 200), showParticles(기본 false).
예시 그룹은 displayName 'Fruit', nutritionSymbol 'Ψ ', decayRate 6, gainMultiplier 1, 색상 스킴 키 'a'를 사용할 수 있습니다. 예시 파일이며 모든 그룹이 같은 스킴을 써야 한다는 요구 사항이 아닙니다.

05아이템, 툴팁, 블록, 품질

데이터팩 디렉터리: items/<itemPath>.json, tooltips/<itemPath>.json, blocks/<blockPath>.json, quality_levels/<id>.json, rarities/<id>.json, effect_lines/<effectId>.json. 아이템/툴팁 항목은 .json.disabled를 지원하고 블록은 지원하지 않습니다. 효과 줄 스타일은 해당 물약 줄이 강제 통일을 선택한 경우에만 아이템을 덮어씁니다.

아이템 필드 그룹

필드의미
nutrition그룹 ID → 음식 변화. 그룹 획득 배율, 평생 계수, 섭취 분할 수가 곱해집니다.
effects섭취 후 물약 설정: 레벨, tick 시간, 확률, 입자, 선택적 신선도 곡선.
foodCooldown단기 maxUses, cooldownCount, cooldownMinutes, restoreHunger.
foodFatigue평생 lossStart와 aversionCount. 둘 다 설정 시에만 선형 감소.
shelf기본 시간, 온도 곡선, 차원 배율, 냉장 신선도/보냉, 환경 온도, 섭취 효과.
onEatCommands / suppressEffects섭취 명령어와 아이템 고유 효과 제거. 각각 고유 지연이 있습니다.
conditionalRules영양 조건 → 대상 변화, 명령어, 힌트. 규칙 전체로 저장.
stackSize아이템 레벨 최대 스택. 0 = 바닐라. 재시작 필요, NBT 변형별 한도 없음.

nbtLock / variantNameNBT 매칭과 주석. 빈 nbtLock은 일반 아이템 항목을 의미.

08게임 내 설정 UI 도해

설정 메뉴(/hdconfig)

/hdconfig는 클라이언트 로컬 명령어이며 실행 자체가 OP4를 확인합니다. 비 OP 플레이어는 다른 게임 화면에서 로컬 외형 설정에 들어갈 수 있지만 이 명령어를 직접 실행할 수는 없습니다. 페이지 목업은 읽기 전용이고 실제 값을 가져오지 않습니다.

클라이언트 외형 · 12개 편집 가능 줄

서버 게임플레이 · 9개 항목과 초기화 작업

온도 연동 · 5개 테이블 + 별도 LSO 항목

5개 서버 테이블 탭은 하나의 초안과 한 번의 검증된 저장을 공유하고 탭을 전환해도 저장하지 않은 변경이 유지됩니다. 6번째는 독립 폼을 엽니다. 아래 탭은 파일 그룹 설명만 하며 데이터를 변경할 수 없습니다.

부패 배율

계절 ID별 배율 0–100. 기본 ×1. 활성 EC 절기와 EC 연동 활성화가 필요. 구 6계절 파일은 6개 항목 유지.

블록 열

블록 이름 또는 ID로 검색. +는 가열, −는 냉각, −1000–1000. 상태별로 별도 규칙을 가질 수 있고 열, 거리, 차폐가 실제 기여를 결정.

낮/밤

절기별 정오/자정 오프셋, 각 −100–100℃(기본 0). 낮 동안 보간되고 바이옴 고유 끝점이 우선.

계절 온도

EC 기후 위에 절기별 추가 −100–100℃(기본 0). EC 없으면 첫 절기 사용.

비/눈

비/눈 기본 −1℃, 뇌우 기본 −2℃, 각 절기 −100–100℃. 천둥은 일반 비 값을 더하지 않음.

LSO 월드 온도

별도 차원 폼이며 5개 테이블 공동 저장에 포함되지 않습니다. 월드 온도 값은 LSO 단위이며 섭씨가 아닙니다.

절기 순서: 입춘, 우수, 경칩, 춘분, 청명, 곡우, 입하, 소만, 망종, 하지, 소서, 대서, 입추, 처서, 백로, 추분, 한로, 상강, 입동, 소설, 대설, 동지, 소한, 대한. 미리보기는 서버의 실제 24개 항목을 읽지 않습니다.

09소유자별 저장과 리로드

변경작업 / 이유
server.jsonOP 화면에서 gameplay 저장. privacy와 shelfMerge는 수동 편집 후 /hdreload. 화면으로 교환되는 것은 gameplay뿐.
display.json, 로컬 안개/템플릿각 클라이언트에서 저장. 수동 편집 후 클라이언트 재시작. 서버 /hdreload는 로컬 파일을 편집할 수 없음.
그룹, 단계, 보너스, 아이템, 툴팁, 블록, 품질, 희귀도, 효과 줄의 HD 오버레이저장 후 /hdreload로 디스크에서 재구성하고 온라인 플레이어에 재동기화. 월드 데이터팩은 바닐라 /reload.
quality_registry/ 항목 또는 stackSize일치하는 정의와 리소스를 배포하고 시작 시 등록/아이템 레벨 속성을 위해 재시작.
