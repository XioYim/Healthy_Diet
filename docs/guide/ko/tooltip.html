05 / TOOLTIP

일반 툴팁과 S/D 상세는 역할이 다릅니다.

아이템 호버 툴팁은 정보 줄을 재배치할 수 있습니다. 플레이어는 화면 안의 표시 키를 눌러 다른 상세를 확인할 수 있고 서버 관리자는 항목별 표시를 설정할 수 있습니다.

아이템 툴팁레이아웃 마커S / D 모드
키 전제: S, D는 기본적으로 인벤토리 등의 화면을 열고 마우스를 아이템에 올렸을 때만 사용할 수 있습니다. 이 키는 클라이언트에서 재지정할 수 있습니다. 웹 페이지 시뮬레이션은 각 모드의 정보 범주만 보여 주며 특정 아이템에 모든 줄이 있다는 뜻은 아닙니다.

이 페이지 목차

  1. 3가지 표시 모드
  2. 줄별 레이아웃
  3. 표시 스위치
  4. 편집과 호환성

01일반, S, D 모드

일반 호버아이템 이름과 항상 표시하도록 설정된 줄을 표시합니다. 실제로는 Shift와 전역 표시 규칙의 영향을 받을 수도 있습니다.
S 누르기보존 기간, 영양, 음식 싫증 등의 상세를 확인합니다. 구체적인 항목에는 해당 음식 설정과 정보 줄이 필요합니다.
D 누르기설명 정보 블록, JEI 정보, 물약 효과, 사용자 지정 infoOnly 텍스트를 표시합니다.
선택은 웹 페이지 설명만 바꾸며 게임이나 서버의 아이템 설정을 읽지 않습니다.

S와 D를 동시에 누르면 나중에 누른 키가 우선합니다. 같은 클라이언트 tick에 동시에 누르면 D가 우선합니다. H는 영양 패널, I는 TitlePro 편집기를 여는 게임 내 키이며 S/D 상세 키가 아닙니다.

인벤토리에서 시험하기

먼저 서버에서 실제로 영양이나 보존 기간이 설정된 음식에 커서를 올리고 일반 호버와 S를 누른 상태를 비교합니다. 다음으로 설명이나 효과 정보가 있는 아이템에서 D를 누릅니다. 해당 내용이 없거나 서버 관리자가 숨긴 줄은 키를 눌러도 나타나지 않습니다. S와 D가 두 페이지 내용을 합치지도 않습니다.

소스 근거: HealthyDietKeys, TooltipHandler.

02툴팁 줄 배치

아이템 툴팁의 추가 줄은 목록 순서대로 렌더링됩니다. 특수 마커 줄은 삽입 위치이며 고정 텍스트를 한 줄로 쓸 필요가 없습니다.

줄 마커표시 정보
영양 / 음식 싫증영양 획득과 쿨다운/거부감 정보
보존 기간 / 품질아이템 보존 기간 상태와 품질 표시
물약 효과설정 효과와 아이템 고유 효과 등
설명 / JEID 모드 정보 블록과 설명 내용
음식 값허기와 통합된 음식 데이터

일반 텍스트 줄은 Shift 전용 또는 상세 모드 전용으로 설정할 수 있습니다. 이름 줄과 일반 추가 줄은 규칙이 다릅니다. 어떤 아이템에 해당 설정이나 내용이 없으면 모든 줄이 표시된다고 기대하지 마세요.

레이아웃 아이디어

영양 정보를 앞에 두고 싶으면 영양 마커를 추가 줄 목록 앞부분에 놓습니다. 서버 관리자 설명을 상세 페이지에 남기고 싶으면 직접 쓴 텍스트 줄에 infoOnly를 설정합니다. 마커는 위치를 담당할 뿐 설정 내용을 생성하지 않습니다. shiftOnly는 추가 줄만 제어하며 Shift를 누르지 않았을 때 아이템 이름을 사라지게 할 수 없습니다.

소스 근거: TooltipLineConfig의 nutritionMarker, cooldownMarker, shelfLifeMarker, effectsMarker, foodBarMarker 등 필드.

03아이템별 표시 설정

툴팁 설정 패널에는 전체 지우기, 설명 정보, 영양, 음식 싫증, 보존 기간, 물약 효과, 음식 값 등의 스위치가 있습니다. 스위치는 표시에만 영향을 주며 음식에 이미 설정된 영양이나 보존 기간 설정을 자동 삭제하지 않습니다.

숨기기와 지우기의 차이

예를 들어 보존 기간 줄을 플레이어에게 보여 주고 싶지 않으면 '보존 기간' 표시 스위치를 조정하면 되고 보존 계산에 영향을 주는 아이템 설정을 삭제할 필요는 없습니다. '전체 지우기'는 다른 모드나 바닐라가 추가한 일반 툴팁 줄을 제거하기 위한 것이며 Healthy Diet가 생성하는 품질, 보존 기간, 영양 등의 줄을 삭제하는 것이 아닙니다. HD 줄을 숨기려면 해당 스위치를 각각 설정하세요.

NBT 변형 제한: 설명 정보와 효과 줄의 일부 스위치는 아이템 레벨 설정이며 변형 페이지에서 잠깁니다. 공통 설정으로 돌아가 조정해야 합니다. 다른 스위치는 해당 아이템이나 변형에 실제 데이터가 있는지로 판단합니다.
소스 근거: TooltipVisibilitySettingsScreen.init의 7줄 버튼과 itemLevelLocked.

04편집 진입점과 D 페이지 소스

서버 관리자가 아이템을 들고 /hdui tooltip (OP4)을 실행합니다. 설정된 NBT 변형이 있으면 아이템 메인 메뉴로 들어가 공통 항목 또는 변형을 선택한 뒤 툴팁을 엽니다. 변형이 없으면 아이템 레벨 공통 툴팁 편집기를 바로 엽니다. D 페이지 정보 블록은 바닐라 설명, JEI, HD 설정, 효과를 집계할 수 있습니다. 사용자가 직접 쓴 줄이 있으면 실제 레이아웃과 덮어쓰기 우선순위로 텍스트와 위치가 결정됩니다.

오른쪽 Ctrl은 관련 효과 상세의 기본 키로 사용할 수 있지만 구체적인 표시는 설치된 JEED/JEI 관련 컴포넌트와 키 설정에 따라 달라집니다. 이 키를 모든 환경에 존재하는 고정 독립 페이지로 설명하지 마세요.

다른 아이템 첫 줄의 색상 스킴과 동적 매개변수만 복제하려면 /hdset tooltip 색상 복제 (OP2)를 사용할 수 있습니다. 세그먼트 텍스트는 편집기에서 세그먼트별로 조정해야 하며 이 명령어로 텍스트를 복제할 수 없습니다.

소스 근거: TooltipHandler의 D 정보 블록 구성, HDUICommand, HealthyDietKeys.JEED_EFFECT_PAGE.
관련 외형툴팁 텍스트의 그라데이션 스킴과 동적 스타일은 표시 내용과 독립적입니다.
