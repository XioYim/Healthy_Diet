/headiet/hdinfo/hdtemperature
읽기 범위: 이 페이지는 플레이어가 확인할 수 있는 규칙과 확인 경로만 설명합니다. 영양 그룹, 단계 임계값, 효과, 보존 기간 매개변수, 명령어 권한은 모두 서버 설정이며 실제 결과는 참여 중인 월드를 따릅니다.

01플레이 시작

  • 1일치하는 파일 설치: Minecraft 버전과 로더에 맞는 Healthy Diet 파일을 사용하세요. 멀티 서버에서는 양쪽 호환성이 필요합니다.
  • 2영양 패널 열기: /headiet를 입력해 자신의 영양 그룹과 현재 값을 확인합니다.
  • 3음식 확인: 음식을 들고 /hdinfo를 입력하면 일치하는 변형의 서버 설정을 확인하고 로컬 음식 쿼리 뷰어를 엽니다. /hdinfo minecraft:apple로 지정 아이템의 기본 스택을 확인할 수도 있습니다.
  • 4툴팁 보기: 아이템 툴팁은 영양, 반복 섭취, 보존 기간 정보를 표시할 수 있습니다. 어떤 줄을 항상 표시하고 어떤 줄을 Shift로 펼칠지는 서버 관리자가 정합니다.
  • 5온도 진단: 서버에서 온도나 계절 연동이 활성화된 경우 /hdtemperature로 현재 소스와 각 기여도를 확인할 수 있습니다.

/hdhelp로 게임 안의 모든 명령어와 인자를 확인할 수 있습니다. 도움말 항목을 클릭해도 채팅 입력창에 들어갈 뿐 자동 실행되지는 않습니다.

02게임플레이 개요

영양새 설정에는 보통 유제품, 과일, 곡물, 단백질, 당분, 채소 6개 그룹이 있습니다. 음식은 여러 그룹에 동시에 영향을 줄 수 있고 그룹 값은 설정에 따라 감소합니다. 단계와 그룹 교차 조건으로 보너스를 얻을 수 있습니다.영양 수치 읽기 →

보존 기간보존 기간이 설정된 음식은 남은 시간을 기록합니다. 환경, 계절, 냉장고, 차원 배율, 사용자 지정 온도대가 보존과 만료 결과에 영향을 줍니다.보존 기간 읽기 →
모든 음식이 같은 규칙으로 제한된다고 가정하지 마세요: 어떤 음식에 싫증, 보존 기간, 효과가 설정되지 않았다면 해당 동작이 저절로 생기지 않습니다. 구체적으로는 서버와 아이템 설정을 따릅니다.

04OP 없이 할 수 있는 것과 자주 묻는 질문

OP 없이 무엇을 쓸 수 있나요?/headiet로 자신의 영양 패널, /hdinfo로 음식, /hdtemperature로 온도 보고서, /hdhelp로 도움말을 확인할 수 있습니다. 서버 규칙 편집에는 관리자 권한이 필요합니다.
쿼리 뷰어에서 음식을 직접 편집할 수 있나요?아니요. 쿼리 뷰어는 서버가 제공한 스냅샷을 표시하고 데이터는 로컬 페이지에 표시됩니다. 새로고침하거나 JSON을 붙여넣어도 게임에 다시 쓰이지 않습니다.
서버를 관리하시나요?명령어 권한, 설정 경로, 데이터팩, 리로드 경계는 서버 관리자 매뉴얼을 참고하세요.
