08 / UTILITIES

액체 채우기부터 블록 상호작용까지, 실제 설정에 따라 작동합니다.

이 페이지는 독립된 소기능과 자주 쓰는 도구 명령어를 모아 설명합니다. 모드가 지원하는 진입점을 보여 주는 것이며 모든 월드에 기본 아이템이나 블록이 설정되어 있다는 뜻은 아닙니다.

액체 우클릭안개 거리블록 상호작용편의 명령어
기능 상태: 블록 우클릭 규칙은 데이터팩을 지원합니다. 블록 설정의 /hdui 시각적 편집 진입점은 아직 완성되지 않았습니다. 블록을 설정할 때는 기존 데이터팩 기능을 사용하고 미완성 화면을 사용 가능한 기능으로 취급하지 마세요.

01액체 공급원 블록에 우클릭으로 채우기

서버 측은 config/healthy_diet/bottle_fills.json의 규칙을 읽습니다. 일치하는 아이템을 들고 지정 액체의 공급원 블록에 우클릭하면 원래 아이템 하나를 소비하고 설정된 결과 아이템을 줍니다. 결과에는 NBT를 붙일 수 있습니다.

즉 '모든 병이 자동으로 물을 담는' 것이 아닙니다. 채울 수 있는 아이템, 액체, 결과는 서버 설정에 따릅니다. 크리에이티브 모드에서는 아이템을 소비하지 않고 결과도 저절로 생성되지 않습니다.

새 설치의 기본 규칙

기본 파일은 minecraft:glass_bottle + minecraft:water 공급원 블록을 물이 든 물약 NBT가 붙은 minecraft:potion으로 설정합니다. 서바이벌 모드에서는 빈 병 하나가 결과로 교체됩니다. 스택을 들고 있으면 결과가 먼저 인벤토리에 들어가고 가득 차면 드롭됩니다. 수정된 서버 파일에는 이 예시가 적용되지 않습니다. 흐르는 액체도 공급원 블록 판정에 일치하지 않습니다.

소스 근거: BottleFillConfig, BottleFillHandler.onRightClickBlock.

02효과에 따라 수중과 용암 안개 조정

클라이언트는 config/healthy_diet/fog_effects.json을 읽습니다. 플레이어가 설정된 물약 효과를 가질 때 수중 안개의 시작/끝 거리와 용암 안개의 끝 거리를 바꿀 수 있습니다. 기본 일치 효과는 야간 투시이며 구체적인 거리는 클라이언트 파일에서 조정할 수 있습니다.

여기서 바뀌는 것은 안개 거리이며 안개 전체를 착색하는 것이 아닙니다. 효과가 끝나 갈 때 거리는 점차 원래 값으로 돌아갑니다. 서버 측 리로드는 각 클라이언트가 로컬 안개 설정을 읽는 것을 대신하지 못합니다.

기본 파일 필드

새 설치의 로컬 기본값은 minecraft:night_vision을 트리거 효과로 하고 waterFogStart=80, waterFogEnd=160, lavaFogEnd=6(단위: 블록)입니다. 효과 목록 중 하나라도 일치하면 이 안개 거리 값을 사용하고 여러 개가 일치하면 목록 순서대로 첫 항목을 사용합니다. 서버 관리자가 플레이어에게 효과를 부여해도 서버가 로컬 안개 거리 파일을 플레이어에게 동기화하는 것은 아닙니다.

소스 근거: FogEffectConfig, FogRendererMixin.

03블록 우클릭과 설치 음식

데이터팩 data/<네임스페이스>/healthy_diet/blocks/<블록경로>.json으로 블록의 우클릭 변형을 정의할 수 있습니다. 블록 상태, 주 손 아이템, 웅크리기 조건에 일치시키고 영양 증감, 물약 효과, 명령어, 소비, 쿨다운, 바닐라 상호작용 취소 여부를 설정합니다.

이 규칙은 서버 측에서 실행됩니다. 설정되지 않은 블록에는 자동 적용되지 않습니다. 케이크처럼 나누어 먹는 설치 음식은 영양 계산을 실제로 먹은 한 입 기준으로 처리하고 케이크 전체 수치를 매 입마다 반복 지급하지 마세요. 보존 기간이 있는 설치 음식은 계속 월드 시간으로 계산됩니다.

하나의 규칙으로 할 수 있는 일

같은 블록 파일에 여러 변형을 쓸 수 있습니다. 예를 들어 hand=item이고 주 손 아이템이 items 목록에 일치할 때만 발동하며 sneak=require는 웅크리기를 요구합니다. consumeItem은 1회 소비 수를 제어하고 cooldownTicks 기본값은 20입니다. 명령어 문자열은 블록 좌표 {x}, {y}, {z}를 참조할 수 있습니다. 이는 필드 예시이며 이 사이트가 제공하는 기본 블록 규칙이 아닙니다.

현재 진입점: 데이터팩으로 블록 규칙을 관리하고 서버에서 리로드하세요. /hdui 메인 메뉴의 블록 시각적 편집은 완성된 기능으로 설명하지 않습니다.
소스 근거: BlockConfig, BlockInteractEvents, ConfigManager.loadBlockConfigsFromPacks.

04자주 쓰는 보조 명령어

명령어용도와 경계
/hdcloneitemOP4. 보조 손의 설정된 항목을 주 손의 대응 항목에 부분적으로 덮어씁니다. 제공되지 않은 설정 그룹은 유지되며 초기화 후 재구성하는 것이 아닙니다.
/cleartoast [플레이어]자신은 OP 불필요, 지정 플레이어는 OP2. 대상 클라이언트의 업적 토스트 큐를 지웁니다. TitlePro 화면 지우기가 아닙니다.
/hdhelp모두 사용 가능. 명령어를 그룹별로 표시하고 호버로 설명을 봅니다. 클릭해도 채팅 입력창에 들어갈 뿐 즉시 실행되지 않습니다.
/hdtemperature모두 사용 가능, 인자 없음. 실행자 현재 위치의 온도 소스와 내역을 표시하고 호버로 분해 정보를 확인합니다. 소스는 환경 연동에 따라 달라집니다.

/hdcloneitem을 사용할 때 설정 소스를 보조 손에, 대상을 주 손에 듭니다. 명령어는 소스에서 실제로 설정된 기능 그룹만 덮어쓰고 대상의 다른 그룹은 유지됩니다. 대상의 품질, 희귀도, 변형 주석도 소스에서 복사되지 않습니다. 명령어 인자와 필요한 권한을 확인하려면 채팅에 /hdhelp를 입력하고 해당 줄에 호버하세요. 명령어 줄을 클릭해도 입력창에 텍스트가 들어갈 뿐 자동 실행되지 않습니다.

명령어마다 권한과 인자가 다릅니다. 설정 변경, 상세 설명, 리로드 진입점은 서버 관리자 매뉴얼을 참고하세요.

소스 근거: HDCloneItemCommand, HDClearToastCommand, HDHelpCommand, HDTemperatureCommand.
