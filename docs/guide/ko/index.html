HEALTHY DIET / FEATURE GUIDE

Healthy Diet 기능 가이드.

영양, 음식 싫증, 품질, 보존 기간, 툴팁, 표시 꾸미기, TitlePro, 편의 기능, 서버 설정을 기능별로 설명합니다. 각 페이지에는 예시, 기본 설정, 서버 실제 규칙의 경계를 명시합니다.

MAP챕터 맵

00 / INTRODUCTION

소개 및 설치

3가지 핵심 규칙, 설치 및 호환성, 데모 영상과 프로젝트 페이지.

먼저 이 페이지 읽기 → 00 / QUICK START

플레이어 입문

3가지 확인 명령어, 게임플레이 개요, 표시와 확인, 자주 묻는 질문.

명령어부터 시작 → 01 / NUTRITION

영양 수치

6개 영양 그룹, 수치와 감소, 단계, 보너스, 조건 규칙, NBT 변형, 관리 명령어.

규칙과 패널 예시 보기 → 02 / FATIGUE

음식 싫증

단기 쿨다운, 회복 조건, 영구적인 영양 감소. 예시 횟수를 조정할 수 있습니다.

첫 버전 보기 → 03 / QUALITY

품질, 희귀도, 아이템 등록

품질 ID, 희귀도 표시, 신규 아이템 등록의 경계와 반영 시점.

첫 버전 보기 → 04 / SHELF LIFE

보존 기간

기본 시간, 온도 곡선, 보냉, 섭취 효과, 멀티 서버 계산.

첫 버전 보기 → 05 / TOOLTIP

툴팁과 상세 모드

표시 줄 배치, 표시 스위치, 일반·S·D 모드의 내용 차이.

첫 버전 보기 → 06 / APPEARANCE

그라데이션과 표시 꾸미기

그라데이션 스킴, 동적 스타일, 단색 팔레트, 전용 툴팁 색상 경로.

첫 버전 보기 → 07 / TITLEPRO

TitlePro와 섭취 효과

타이틀 편집기, 명령어, 섭취 시 물약 효과, 아이템 명령어.

첫 버전 보기 → 08 / MISC

소기능 모음

액체 채우기, 안개 거리, 블록 우클릭 규칙, 편의 명령어.

첫 버전 보기 → 09 / ADMIN

서버 관리자 매뉴얼

현재 설정 경로, 데이터팩 오버레이, 리로드와 클라이언트 동기화 경계.
