02server.json: server-authoritative sections

One file has three sections: gameplay, privacy, shelfMerge. Older separate files migrate into this one and move to migration_backup/.

FieldNew-file defaultBehavior
shelfTemperatureEnabledfalseMaster switch for shelf life and temperature. Off pauses decay, temperature/freshness, expiration products and commands, temperature rejection, zone effects and associated tooltip lines; existing item data remains and downtime is not retroactively charged.
lsoIntegrationEnabledtruePermit hd:shelf to read the complete LSO world environment. Does not disable other LSO compatibility.
ecIntegrationEnabledtruePermit direct EC climate and HD seasonal spoilage multipliers, without changing EC data already supplied by LSO.

bonusUpdateTicks100Attribute-bonus refresh interval (1–1,728,000 ticks; about five seconds by default).
effectUpdateTicks200Potion-bonus refresh interval (1–1,728,000 ticks; about ten seconds by default).
ejectIllegalProtectedItemsfalseIf an untrusted holder has a protected item: true drops it at their feet; false freezes it in place and warns. Default avoids losing items due to misclassification.

The OP in-game server screen saves gameplay only. Edit privacy and shelfMerge on disk, then /hdreload. A read-only file causes the save to fail without changing authoritative in-memory values.

04Nutrition datapack: groups, stages and bonuses

Paths under data/<namespace>/healthy_diet/ are nutrition_groups/<groupId>.json (one group definition), nutrition_stages/<groupId>.json (stages + hideAutoBonus), and nutrition_bonuses/<groupId>.json (remark + bonuses). The HD override goes under config/healthy_diet/datapack/; filenames are group IDs. At most 64 groups.

Group fields

FieldDefaultExplanation
displayNameGroupGroup label shown in UI/tooltips; bundled defaults may have localized names.
nutritionSymbolΨ Nutrition-line prefix; blank falls back to the default plus a space.
order0Ascending display order, tie-broken by group ID.
color / colorStyle#FFFFFF / nullHex solid color or scheme key. Style controls dynamic/nameStyle/speed/steps/waveStep/pulseDelay/reversals/bold/italic/underlined for schemes; ignored for solid colors.
decayRate6.0Every consumed hunger point reduces nutrients by 1/decayRate; nonpositive disables natural decay.
iconemptyOptional item icon resource; blank uses UI fallback.
initialValue0Starting group value for a new player or newly added group, 0–100.
gainMultiplier1Multiplies positive and negative food changes; 0 allowed; negative/nonfinite values fall back to 1. Final group value clamped to 0–100.
enabledtrueDisabling hides/freezes the group for all players and stops decay, conditions and bonuses.
requiredPlayerTagemptyExact player scoreboard tag required; blank means no restriction. Not an item/block tag.
requiredModIdemptyLoaded server mod ID required; blank means no restriction.
nutritionTipColorsgeneratedFour slots: regular/conditional × gain/loss; customization controls whether gain follows the group-name color.

Stage and bonus fields

FieldDefaultExplanation
stages[].min/max0/100Inclusive integer bounds; checks round the current value first. Adjacent stages cannot overlap or leave gaps.
stages[].label/tooltip/commandsempty / [] / []Optional title, extra hover lines and configured stage commands; command text is only sent to OP4 unless privacy permits more.
hideAutoBonusfalseIf true, suppress automatic range title and bonus preview in all stage tooltips for this group.
remarkemptyEditor list label; blank uses filename, does not affect settlement.

bonuses[].attributeBonuses[][]attribute (default max_health), operation add/multiply_base/multiply_total (default add), value.
bonuses[].effectBonuses[][]effect ID, level (0=I), duration ticks (default 200), showParticles (default false).
An example group may use displayName “Fruit”, nutritionSymbol “Ψ ”, decayRate 6, gainMultiplier 1 and color scheme key “a”; this is an illustrative file, not a requirement that every group use the same scheme.

05Items, tooltips, blocks and quality

Datapack directories: items/<itemPath>.json, tooltips/<itemPath>.json, blocks/<blockPath>.json, quality_levels/<id>.json, rarities/<id>.json, effect_lines/<effectId>.json. Item/tooltip entries support .json.disabled; blocks do not. Effect-line style overrides an item only when its potion row opts into force-unify.

08In-game configuration UI diagrams

Configuration menu (/hdconfig)

/hdconfig is a client-local command that itself checks OP4. Non-OP players can reach local appearance settings from other game screens, but cannot invoke this command directly. The page mockups are read-only; no real values are retrieved.

Client appearance · twelve editable rows

Server gameplay · nine entries and reset action

Temperature integrations · five tables + separate LSO entry

Five server table tabs share one draft and one validated Save; changing tabs retains unsaved changes. The sixth opens an independent form. The tabs below explain file groups only; they cannot modify any data.

Spoilage multipliers

Per-season ID rate 0–100; default ×1; requires an active EC term and enabled EC integration. Legacy six-season files remain six entries.

Block heat

Search block name or ID; + values heat and − cool, −1000–1000. States can have separate rules; heat, distance and occlusion determine actual contribution.

Day/night

Noon and midnight offsets per term, each −100–100°C (default 0), interpolated during the day; biome-specific endpoints take precedence.

Seasonal temperature

Additional −100–100°C per term (default 0) on top of EC climate; without EC uses the first term.

Rain/snow

Rain/snow default −1°C, thunderstorm default −2°C per term, both −100–100°C; thunder does not add the ordinary rain value.

LSO world temperature

Separate dimension form, not part of the five-table combined save; world-temperature values use LSO units, not Celsius.

Term order: Beginning of Spring, Rain Water, Awakening of Insects, Spring Equinox, Clear and Bright, Grain Rain, Beginning of Summer, Grain Full, Grain in Ear, Summer Solstice, Minor Heat, Major Heat, Beginning of Autumn, End of Heat, White Dew, Autumn Equinox, Cold Dew, Frost Descent, Beginning of Winter, Minor Snow, Major Snow, Winter Solstice, Minor Cold, Major Cold. The preview does not load the 24 actual server entries.

09Save and reload by owner

ChangeAction / reason
server.jsonSave gameplay in OP screen; manually edit privacy and shelfMerge then /hdreload. Only gameplay is exchanged through the screen.
display.json, local fog / templatesSave on each client; restart the client after manual edits. Server /hdreload cannot edit local files.
HD override of groups, stages, bonuses, items, tooltips, blocks, quality, rarity and effect linesSave and /hdreload to reconstruct from disk and resynchronize online players. For world datapacks, use vanilla /reload.
quality_registry/ entry or stackSizeDistribute matching definitions and resources; restart for startup registration / item-level attribute.
Client textures and fontsInstall on each client; a server-side reference cannot transmit resources.
/hdreload is not vanilla /reload: world packs, other mods and local client files each have their own reload mechanism.
