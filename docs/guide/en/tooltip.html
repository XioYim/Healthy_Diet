05 / TOOLTIP

Tooltips and S/D detail modes

Item tooltips can reorder lines and show separate details on demand; the server owner can hide individual categories.

Normal hoverHold SHold D
Keybinding boundary: S and D are used by default while hovering items in inventory-like screens and can be rebound on the client. Not every food has every line.

On this page

  1. Normal, S and D
  2. Line-by-line layout
  3. Per-item visibility
  4. Editing and D-page sources

01Normal, S and D

Normal hoverItem name and always-visible lines; Shift and global settings may change what appears.
Hold SShelf-life, nutrition and fatigue details when the food has the corresponding configuration.
Hold DInformation blocks, JEI content, potion effects and custom infoOnly text.
This preview does not query a game or server.

When S and D are held together, the last pressed key wins; if pressed during the same client tick, D wins. H opens the nutrition screen and I opens TitlePro; neither is an S/D detail key.

02Line-by-line layout

MarkerWhat appears
Nutrition / fatigueNutrition changes and cooldown / aversion.
Shelf life / qualityCurrent shelf-life state and quality label.
Potion effectsConfigured and intrinsic effects.
Information / JEIThe D-mode information block and descriptions.
Food valuesHunger and integrated dietary data.

Marker rows set insertion points; they do not generate missing configuration. Ordinary lines can be Shift-only or detail-only. shiftOnly applies to extra lines, not to hiding the item name. Use infoOnly for custom text that belongs on D.

03Per-item visibility

The visibility screen has controls for clearing normal lines, information, nutrition, fatigue, shelf life, potion effects and food values. Hiding a line does not delete the underlying food data. “Clear entire tooltip” removes ordinary lines supplied by vanilla or other mods, not the Healthy Diet lines it generates; hide HD categories with their own switches.

Some description/effect visibility switches are item-level and locked in an NBT-variant screen. Edit the generic entry instead.
Potion effect row display: "Default: Effects Row Shift-Only" is OFF by default. When ON, every item's visible potion and status effect rows are shown by this mod, while vanilla, other mod and LSO effect rows are hidden; holding Shift shows the unified effect row, and without Shift the effect row is hidden. "Show Forced Unified Potion Styles" is ON by default and is the display master switch; when OFF, vanilla and other mod effect rows are not replaced. "Unify Potion Effect Style for All Items" is OFF by default; when ON with the master switch on, all visible potion effects use the unified format and override per-item settings, while OFF follows each item's own force-unify setting. When both switches are ON, the unified effect row appears only while holding Shift.

04Editing and D-page sources

With an item in hand, use /hdui tooltip (OP4). If configured NBT variants exist, first select the generic entry or a variant; otherwise the generic tooltip editor opens immediately. D may combine vanilla, JEI, Healthy Diet and effect information with custom text according to the item layout and precedence. Right Ctrl may show JEED-related effect details when the corresponding components and bindings are installed; it is not a universal standalone page.

To copy only the generic first-line color scheme and animation fields, see /hdset tooltip (OP2). It cannot copy segmented text.
