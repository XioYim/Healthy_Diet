08 / UTILITIES

Utilities and small features

01Right-click a fluid source to fill

The server reads config/healthy_diet/bottle_fills.json: with a matching held item, right-click a specified source block to consume one item and receive the configured result, optionally with NBT. It is not automatic filling for every bottle. A fresh install includes glass bottle + water source → water potion NBT; a modified server may differ. With a stack, the result goes to inventory or drops if full. Creative mode neither consumes nor creates a result; flowing fluids do not match.

02Underwater and lava fog distance

The client reads config/healthy_diet/fog_effects.json and changes underwater fog start/end and lava fog end while a listed effect is active. The fresh local default uses Night Vision and values 80 / 160 / 6 blocks; first matching effect wins. As an effect expires, distances transition back smoothly. This is fog distance, not fog color. A server reload cannot remotely edit each client’s local file.

03Block right-click and placed food

Datapack data/<namespace>/healthy_diet/blocks/<blockPath>.json can define variants matching block state, main-hand item and sneaking. Configure nutrition, potions, commands, item consumption, cooldown and whether vanilla interaction is canceled. Multiple variants may share a file; hand=item matches items, sneak=require requires sneaking, consumeItem controls consumption, cooldownTicks defaults to 20, and commands may contain {x}, {y}, {z}. Rules execute server-side; none are automatically attached to unconfigured blocks. For cakes, credit the portion actually eaten rather than a whole cake per bite; placed foods with shelf life still use world time.

Block datapack rules are supported, but the /hdui visual block editor is not finished. Edit the datapack and reload instead.

04Utility commands

CommandPermissions and effect
/hdcloneitemOP4. Configured groups from the off-hand item locally overwrite corresponding groups on the main-hand item; absent groups on the source leave target groups intact. Quality, rarity and variant notes are not copied.
/cleartoast [player]Self: no OP. Another player: OP2. Clears that client’s advancement-toast queue, not TitlePro.
/hdhelpAvailable to everyone. Hover for descriptions; click to fill the chat input without executing.
/hdtemperatureAvailable to everyone. Inspect temperature sources and breakdown at the executor’s location, with hover details.

Use server administration for configuration scope and reload rules.
