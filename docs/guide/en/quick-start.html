Start with three commands

You do not need to study every configuration file first. Check your nutrients, the food in your hand and the current temperature in game.

/headiet/hdinfo/hdtemperature
Scope: Groups, stage thresholds, effects, shelf-life parameters and command permissions are server-controlled. Your world may differ.

01Get started

  1. Install a Healthy Diet file compatible with your Minecraft version and mod loader; on multiplayer, client and server must be compatible.
  2. Use /headiet to open your nutrition panel.
  3. Hold food and use /hdinfo to view the server configuration for the matching NBT variant in the local viewer; /hdinfo minecraft:apple queries a default stack.
  4. Check the item tooltip for nutrition, fatigue and shelf life. The server owner decides which lines are always visible and which expand with Shift.
  5. When temperature / season integration is enabled, use /hdtemperature to inspect the current sources and contributions.

/hdhelp lists commands and parameters in game. Clicking an entry fills the chat input; it does not run the command.

02Gameplay at a glance

NutritionA fresh configuration commonly has dairy, fruit, grains, protein, sugar and vegetables. Food may affect multiple groups; decay, stages and cross-group bonuses are configurable.
Repeat eatingShort-term food cooldowns and lifetime aversion are separate per-food rules.
Shelf lifeOnly configured foods track remaining time; environment, seasons, refrigerators, dimensions and temperature zones affect the outcome.
Do not assume every food has every restriction: absent configuration does not magically create fatigue, shelf life or effects.

04Permissions and common questions

What works without OP?/headiet for your own panel, /hdinfo, /hdtemperature and /hdhelp. Server editing needs administrator permissions.
Can the viewer edit food?No. It displays a snapshot sent by the server or locally pasted JSON; refreshing the page never writes back to the game.
