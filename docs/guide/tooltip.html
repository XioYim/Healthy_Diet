05 / TOOLTIP

普通提示与 S/D 详情各有分工。

物品悬浮提示可重排信息行；玩家按住界面内的显示键查看不同详情，服主还能逐项设定可见性。

物品提示布局标记S / D 模式
按键前提：S、D 默认只在打开背包等界面、且鼠标悬浮物品时使用；这些键位可由客户端重新绑定。网页模拟仅显示各模式的内容类别，不代表具体物品会有全部提示行。

本页目录

  1. 三种显示模式
  2. 按行排版
  3. 显示开关
  4. 编辑与兼容

01普通、S、D 模式

普通悬浮显示物品名和配置为常显的行；实际还可能受 Shift 与全局显示规则影响。
按住 S查看保质期、营养、厌倦等详情；具体项目需要相应的食物配置与信息行。
按住 D查看说明信息块、JEI 资料、药水效果与自定义 infoOnly 文本。
选择仅改变网页说明，不会读取游戏或服务器上的物品配置。

S、D 同时按住时，后按下的键优先；同一个客户端 tick 同时按下时 D 优先。H 打开营养面板，I 打开 TitlePro 编辑器，二者是游戏内按键而非 S/D 详情按键。

在背包里试一试

先悬浮一个服务器确实配置了营养或保质期的食物，比较普通悬浮与按住 S；再悬浮有说明或效果信息的物品按住 D。没有相应内容或被服主隐藏的行不会因为按键而出现；S 和 D 也不会把两页内容合并。

源码依据：HealthyDietKeys、TooltipHandler。

02提示按行排列

物品 Tooltip 的额外行按列表顺序渲染；特殊标记行是插入位置，不需要写成一行固定文字。

行标记显示的信息
营养 / 厌倦营养获取与冷却/厌食信息
保质期 / 品质物品的保质期状态与品质标识
药水效果配置效果与物品固有效果等
说明 / JEID 模式的信息块及说明内容
饮食值饱食与其他已集成饮食数据

普通文字行可以选择仅在 Shift 或详情模式显示；名称行与普通附加行的规则不同。某物品没有对应配置或内容时，不应预期所有行都会出现。

排版思路

希望营养信息靠前，就把营养标记放在附加行列表前部；想把服主说明留在详情页，则给自写文字行设置 infoOnly。标记负责定位而不是生成配置内容；shiftOnly 只控制附加行，不能让物品名称在未按 Shift 时消失。

源码依据：TooltipLineConfig 的 nutritionMarker、cooldownMarker、shelfLifeMarker、effectsMarker、foodBarMarker 等字段。

03逐物品显示设置

Tooltip 设置面板包含整条清空、说明信息、营养、厌倦、保质期、药水效果和饮食值等开关。开关影响显示，不会自动删除食物已有的营养或保质期配置。

隐藏与清空的区别

例如不想让玩家看到保质期行，调整「保质期」显示开关即可，不必删掉会影响保鲜结算的物品配置。「整条清空」用于去掉其他模组或原版加入的普通提示行，不等于删除 Healthy Diet 自己生成的品质、保质期、营养等行；要隐藏 HD 行请分别设置相应开关。

NBT 变体限制：说明信息与效果行的部分开关是物品级设定，在变体页会锁定；应回到通用配置调整。其他开关需按该物品或变体实际是否有数据判断。
源码依据：TooltipVisibilitySettingsScreen.init 的七行按钮与 itemLevelLocked。

04编辑入口与 D 页来源

服主手持物品使用 /hdui tooltip，按当前物品是否存在 NBT 变体进入主菜单选行或通用排版编辑器。D 页的信息块可聚合原版说明、JEI、HD 配置与效果；有用户自写的行时，以实际布局和覆盖优先级决定文字与位置。

右 Ctrl 可作为相关效果详情的默认键位，但其具体呈现依赖已安装的 JEED/JEI 相关组件与键位设置；不要将该键描述为所有环境都有的固定独立页面。

源码依据：TooltipHandler 的 D 信息块构建、HDUICommand、HealthyDietKeys.JEED_EFFECT_PAGE。
