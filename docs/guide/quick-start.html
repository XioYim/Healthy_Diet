01开始游玩

  • 1安装匹配的文件：使用与你的 Minecraft 版本和加载器匹配的 Healthy Diet 文件；多人服务器两端须兼容。
  • 2打开营养面板：输入 /headiet 查看自己的营养组和当前值。
  • 3查询食物：手持食物输入 /hdinfo，查看匹配变体的服务端配置并打开本机食物查询器；也可用 /hdinfo minecraft:apple 查询指定物品的默认堆叠。
  • 4看 Tooltip：物品提示可以展示营养、重复进食和保质期信息；服主决定哪些行常显、哪些按 Shift 展开。
  • 5诊断温度：服务器启用温度或季节联动时，用 /hdtemperature 查看当前来源和各项贡献。

/hdhelp 可在游戏内查看全部命令及参数；点击帮助项只会填入聊天框，不会自动执行。

02玩法概览

营养新配置通常提供乳制品、水果、谷物、蛋白质、糖分、蔬菜六组；食物可同时供给多组，组值会按配置衰减，阶段与跨组条件可给加成。阅读营养值 →
重复进食短期厌倦限制短时间内重复吃同一种食物；长期厌食按累计进食记录削弱收益。两者都按食物配置。阅读食物厌倦 →
保质期配置了保质期的食物会记录剩余时间；环境、季节、冰箱、维度倍率和自定义温区影响保存与到期结果。阅读保质期 →
不要假定所有食物都受同一套规则限制：某个食物没有配置厌倦、保质期或效果时，就不会凭空出现对应行为；具体以服务器和物品配置为准。

03显示与查询

Tooltip 与详情模式普通、S、D 模式显示的内容不同；常显行和 Shift 行由物品布局与显示开关决定。阅读 Tooltip →
品质、品级与显示美化品质 ID、稀有度标签、渐变色、动态样式和专属提示配色。阅读品质 → · 显示美化 →
TitlePro同一模组附带的屏幕文字系统，可显示标题、表格和颜色覆盖层；不是进食前置。阅读 TitlePro →
食物查询器独立单文件页面，可查看内置案例，也可粘贴自己的 /hdinfo JSON；只读，不回写游戏。打开查询器 →

04无 OP 与常见问题

没有 OP 能用什么？/headiet 看自己的营养面板，/hdinfo 查食物，/hdtemperature 看温度报告，/hdhelp 看帮助。编辑服务器规则需要管理员权限。
查询器能直接编辑食物吗？不能。查询器显示服务端提供的快照，数据在本机网页展示；刷新或粘贴 JSON 都不会回写游戏。
旧教程的配置目录能直接复制吗？

不能假定。当前通用结构包括 config/healthy_diet/server.json、shelf_life/、colors/、temperature/ 等；旧教程里的 shelf_env/、rarity_and_colors/ 和多个独立服务端文件不能直接照搬。升级前备份配置，并核对实际安装文件。

准备管理服务器？命令权限、配置路径、数据包与重载边界见服主手册。
