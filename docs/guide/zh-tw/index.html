HEALTHY DIET / FEATURE GUIDE

Healthy Diet 功能指南。

依功能閱讀營養、食物厭倦、品質、保存期限、Tooltip、顯示美化、TitlePro、實用功能與服主設定。每頁註明範例、預設設定與伺服器實際規則的邊界。

MAP章節地圖

00 / INTRODUCTION

介紹與安裝

三條核心規則、安裝與相容性、示範影片與專案頁。

先讀這一頁 → 00 / QUICK START

玩家入門

三個查詢指令、玩法概覽、顯示查詢與常見問題。

從指令開始 → 01 / NUTRITION

營養值

六組營養、數值與衰減、階段、加成、條件規則、NBT 變體與管理指令。

檢視規則與面板示意 → 02 / FATIGUE

食物厭倦

短期冷卻、恢復條件與終身營養衰減；可調整範例次數。

檢視首版 → 03 / QUALITY

品質、品級與物品註冊

品質 ID、稀有度標籤與新物品註冊的邊界及生效時機。

檢視首版 → 04 / SHELF LIFE

保存期限

基礎時長、溫度曲線、保冷、食用效果與多人伺服器結算。

檢視首版 → 05 / TOOLTIP

Tooltip 與詳情模式

提示行排版、顯示開關與普通、S、D 模式的內容區別。

檢視首版 → 06 / APPEARANCE

漸層色與顯示美化

漸層方案、動態樣式、純色板與專屬提示配色路徑。

檢視首版 → 07 / TITLEPRO

TitlePro 與食用效果

標題編輯器、指令、食用藥水效果和物品指令。

檢視首版 → 08 / MISC

小功能合集

液體裝填、霧距、方塊右鍵規則與實用指令。

檢視首版 → 09 / ADMIN

服主手冊

現行設定路徑、資料包覆蓋層、重載與用戶端同步邊界。

檢視首版 →

TOOL配套工具與參考
