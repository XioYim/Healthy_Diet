05 / TOOLTIP

普通提示與 S/D 詳情各有分工。

物品懸浮提示可重排資訊行；玩家按住介面內的顯示鍵檢視不同詳情，服主還能逐項設定可見性。

物品提示版面標記S / D 模式
按鍵前提：S、D 預設只在開啟背包等介面、且滑鼠懸浮物品時使用；這些鍵位可由用戶端重新綁定。網頁模擬僅顯示各模式的內容類別，不代表具體物品會有全部提示行。

本頁目錄

  1. 三種顯示模式
  2. 依行排版
  3. 顯示開關
  4. 編輯與相容

01普通、S、D 模式

普通懸浮顯示物品名稱和設定為常駐顯示的行；實際還可能受 Shift 與全域顯示規則影響。
按住 S檢視保存期限、營養、厭倦等詳情；具體項目需要對應的食物設定與資訊行。
按住 D檢視說明資訊塊、JEI 資料、藥水效果與自訂 infoOnly 文字。
選擇僅改變網頁說明，不會讀取遊戲或伺服器上的物品設定。

S、D 同時按住時，後按下的鍵優先；同一個用戶端 tick 同時按下時 D 優先。H 開啟營養面板，I 開啟 TitlePro 編輯器，兩者是遊戲內按鍵而非 S/D 詳情按鍵。

在背包裡試一試

先懸浮一個伺服器確實設定了營養或保存期限的食物，比較普通懸浮與按住 S；再懸浮有說明或效果資訊的物品按住 D。沒有對應內容或被服主隱藏的行不會因為按鍵而出現；S 和 D 也不會把兩頁內容合併。

原始碼依據：HealthyDietKeys、TooltipHandler。

02提示依行排列

物品 Tooltip 的額外行依清單順序呈現；特殊標記行是插入位置，不需要寫成一行固定文字。

行標記顯示的資訊
營養 / 厭倦營養取得與冷卻/厭食資訊
保存期限 / 品質物品的保存期限狀態與品質標識
藥水效果設定效果與物品固有效果等
說明 / JEID 模式的資訊塊及說明內容
飲食值飽食與其他已整合飲食資料

普通文字行可以選擇僅在 Shift 或詳情模式顯示；名稱行與普通附加行的規則不同。某物品沒有對應設定或內容時，不應預期所有行都會出現。

排版思路

希望營養資訊靠前，就把營養標記放在附加行清單前部；想把服主說明留在詳情頁，則給自寫文字行設定 infoOnly。標記負責定位而不是生成設定內容；shiftOnly 只控制附加行，不能讓物品名稱在未按 Shift 時消失。

原始碼依據：TooltipLineConfig 的 nutritionMarker、cooldownMarker、shelfLifeMarker、effectsMarker、foodBarMarker 等欄位。

03逐物品顯示設定

Tooltip 設定面板包含整條清空、說明資訊、營養、厭倦、保存期限、藥水效果和飲食值等開關。開關影響顯示，不會自動刪除食物已有的營養或保存期限設定。

隱藏與清空的區別

例如不想讓玩家看到保存期限行，調整「保存期限」顯示開關即可，不必刪掉會影響保鮮結算的物品設定。「整條清空」用於去掉其他模組或原版加入的普通提示行，不等於刪除 Healthy Diet 自己生成的品質、保存期限、營養等行；要隱藏 HD 行請分別設定對應開關。

NBT 變體限制：說明資訊與效果行的部分開關是物品層級設定，在變體頁會鎖定；應回到通用設定調整。其他開關需依該物品或變體實際是否有資料判斷。
藥水效果列顯示：「預設效果列僅 Shift 顯示」預設關閉；開啟後全部物品的可見藥水與狀態效果列由本模組顯示，原版、其他模組與 LSO 的效果列隱藏，按住 Shift 時顯示統一效果列，不按 Shift 時不顯示效果列。「顯示強制統一藥水樣式」預設開啟，是藥水效果列的顯示總開關，關閉時不取代原版或其他模組的效果列。「全部物品統一藥水效果樣式」預設關閉；開啟且總開關開啟時，全部物品的可見藥水效果使用統一格式，覆蓋單物品設定，關閉時僅按各物品自己的強制統一設定顯示；兩個開關同時開啟時，統一效果列僅在按住 Shift 時顯示。
原始碼依據：TooltipVisibilitySettingsScreen.init 的七行按鈕與 itemLevelLocked。

04編輯入口與 D 頁來源

服主手持物品執行 /hdui tooltip (OP4)：有已設定 NBT 變體先進入物品主選單，選擇通用條目或變體再開啟 Tooltip；沒有變體則直接開啟物品層級通用 Tooltip 編輯器。D 頁的資訊塊可聚合原版說明、JEI、HD 設定與效果；有使用者自寫的行時，以實際版面與覆蓋優先級決定文字與位置。

右 Ctrl 可作為相關效果詳情的預設鍵位，但其具體呈現取決於已安裝的 JEED/JEI 相關元件與鍵位設定；不要將該鍵描述為所有環境都有的固定獨立頁面。

只需複製另一個物品首行的配色方案與動態參數時，可以使用 /hdset tooltip 配色複製 (OP2)；分段文字需在編輯器中逐段調整，不能靠該指令複製文字。

原始碼依據：TooltipHandler 的 D 資訊塊建構、HDUICommand、HealthyDietKeys.JEED_EFFECT_PAGE。
相關外觀提示文字的漸層方案與動態樣式獨立於顯示內容。
