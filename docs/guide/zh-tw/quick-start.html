01開始遊玩

  • 1安裝相符的檔案：使用與你的 Minecraft 版本和載入器相符的 Healthy Diet 檔案；多人伺服器兩端須相容。
  • 2開啟營養面板：輸入 /headiet 檢視自己的營養組和目前數值。
  • 3查詢食物：手持食物輸入 /hdinfo，檢視相符變體的伺服器設定並開啟本機食物查詢器；也可用 /hdinfo minecraft:apple 查詢指定物品的預設堆疊。
  • 4看 Tooltip：物品提示可以顯示營養、重複進食和保存期限資訊；服主決定哪些行常駐顯示、哪些按 Shift 展開。
  • 5診斷溫度：伺服器啟用溫度或季節連動時，用 /hdtemperature 檢視目前來源和各項貢獻。

/hdhelp 可在遊戲內檢視全部指令及參數；點擊說明項目只會填入聊天框，不會自動執行。

02玩法概覽

營養新設定通常提供乳製品、水果、穀物、蛋白質、糖分、蔬菜六組；食物可同時供給多組，組值會依設定衰減，階段與跨組條件可給予加成。閱讀營養值 →
重複進食短期厭倦限制短時間內重複吃同一種食物；長期厭食依累計進食記錄削弱收益。兩者都依食物設定。閱讀食物厭倦 →
保存期限設定了保存期限的食物會記錄剩餘時間；環境、季節、冰箱、維度倍率和自訂溫區影響保存與到期結果。閱讀保存期限 →
不要假定所有食物都受同一套規則限制：某個食物沒有設定厭倦、保存期限或效果時，就不會憑空出現對應行為；具體以伺服器和物品設定為準。

03顯示與查詢

Tooltip 與詳情模式普通、S、D 模式顯示的內容不同；常駐行和 Shift 行由物品版面與顯示開關決定。閱讀 Tooltip →
品質、品級與顯示美化品質 ID、稀有度標籤、漸層色、動態樣式和專屬提示配色。閱讀品質 → · 顯示美化 →
TitlePro同一模組附帶的螢幕文字系統，可顯示標題、表格和顏色覆蓋層；不是進食前置。閱讀 TitlePro →
食物查詢器獨立單檔案頁面，可檢視內建案例，也可貼上自己的 /hdinfo JSON；唯讀，不回寫遊戲。開啟查詢器 →

04無 OP 與常見問題

沒有 OP 能用什麼？/headiet 看自己的營養面板，/hdinfo 查食物，/hdtemperature 看溫度報告，/hdhelp 看說明。編輯伺服器規則需要管理員權限。
查詢器能直接編輯食物嗎？不能。查詢器顯示伺服器提供的快照，資料在本機網頁展示；重新整理或貼上 JSON 都不會回寫遊戲。
準備管理伺服器？指令權限、設定路徑、資料包與重載邊界見服主手冊。
